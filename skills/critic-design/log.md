## 2. Проходы
0. **Инвентарь — числа до глаз** (✓ Влад 23.10, режим Б; скилл `screen-inventory`): `inventory.js` → JSON → `inventory_check.py --profile <из карты композиции> [--premium] [--layered]`. Таблица целиком в отчёт, первой. Если дизайнер уже приложил свою таблицу — прогнать заново (значения должны совпасть) и проверить его строки «починил / оправдано» по каждому ✗: оправдание без причины из задачи пользователя или STATE — находка; тот же показатель снят > 3 раз в проекте с одной причиной (STATE «Снятия порогов») — находка лиду «порог пересмотреть, не снимать» (0.6.1). Гейты недобора (`void_pct`, `blank_gap`, `lead_ratio`) читать вместе с 1ж: ✗ по ним на «строгом» паспорте = вайрфрейм вместо премиума. ✗ **не возвращает** экран сам по себе; возвращают смысловые находки проходов ниже. У вариантов — таблицы одинаковые → варианты не разные (находка).
0б. **Карта композиции** (скилл `screen-composition`): файл `<экран>-composition.md` есть? Герой один и он на экране там, где заявлен? Плотность обоснована задачей (сравнивают N строк → строки/таблица, не карточки)? У каждого приёма — принцип и вопрос пользователя? Прогон по `shared-taste` §2а (дефолты-автопилота) — каждый пункт «нет | есть, потому что …»; «есть» без причины — находка «автопилот». Reflex-check (0.6.1): строка (в) совпадает с (а) или с (б) — находка «автопилот первого / второго порядка»; «Вариативность» против последних 3 экранов — тот же каркас без «намеренно» — находка. Нет карты → находка «вернуть» без остальных проходов (экран собран без композиции).
1. **Вслепую, как пользователь** (скриншот экрана): тест 5 секунд — что это за экран, что главное, что сделать; куда смотрит глаз первым; есть ли «серые призраки», шум, спор двух фокусов. Тест «дорогой продукт или бутстрап-шаблон?».
1а. **Против стилевого рефа** (✓ Влад 30.09, урок пилота №1 v1 — критик пропустил «сыро»): скриншот экрана рядом с выбранным рефом стиля (у Mayors — П9, `crops/P9.png`) и паспортом стиля. Узнаётся ли язык рефа поблочно (углы, плитки, типографика размером, чипы, образы, ритм)? Экран, похожий на вайрфрейм с цветом, — находка «вернуть» независимо от чистоты линта.
1б. **Эстетический проход** (✓ Влад 30.09). Сначала **«рядом с рефом»**: наш экран и выбранный реф-опора в одном масштабе — встал бы наш экран в приложение рефа незаметно? Где хуже — конкретно (отступы, кегли, иконки, кнопки, скругления). Затем: экран рядом с 2–3 лучшими рефами своей опоры и с `shared-taste` (§1 нравится, §2 скучно / слоп, `bad/`). Лучше или хуже рефов — по признакам: элементы не дефолтные? сетка не обычная? работа с цветом? иконки, заголовки, тексты, кнопки, размеры — продуманы? шлифовка (одна шкала радиусов, веса, ритм, навбар)? «Не стыдно показать?» — нет → вернуть.
1в. **Механическая проверка перед сдачей** (из taste-skill Leonxlnx, ✓ Влад 30.09) — провал любого пункта = не готово: одна шкала радиусов (**несколько радиусов допустимы, когда каждый закреплён за типом элемента** — пилюля у фильтров, малый у контейнеров, прямой у меток; находка — один тип элемента с разными углами; Влад 04.10, `good-24`); один акцент на весь экран; одна тема на экран; нет двух действий с одним смыслом; **одно состояние — один сигнал** (выбранный чип / вкладка / пункт показан заливкой или обводкой — без галочки, точки или значка поверх; Влад 04.10); ≤ 2 фирменных приёма и ровно 4 фирменных компонента по паспорту; нет нумерации разделов и декоративных точек; нет лишних пилюль / бейджей / мелких подписей; нет повторяющихся карточек-статистик и фейковых графиков; живые данные, а не «идеальные» числа; кнопки не переносятся на 2 строки; каждый текст перечитан (грамматика иврита, нет выдуманных фраз); контраст CTA и полей AA.
1д. **Сверка с закономерностями хороших** (✓ Влад 03.10, пункты 13–17 — 04.10; `shared-taste` §0) — после 1б, по скриншоту, по каждому пункту «да / нет / не относится» с местом на экране: (1) цветов 3–4, у каждого одна роль, акцент ≤ 3 мест; (2) цвет идёт от объекта / образа; (3) иерархия размером и весом, числа главные, пара «подпись / значение»; (4) одна шкала радиусов и одна форма; (5) разделяют тон и воздух, обводка волосяная, тень только у слоя выше; (6) выдумка в 1–3 местах, остальное тихое; (7) фон и материал — по паспорту направления; (8) данные нарисованы материалом интерфейса, нет волны без осей и голого кольца; (9) образы одного набора, в палитре; (10) статус и тег — цвет один раз; (11) навигация тихая; (12) иконки в вес шрифта, на главной кнопке не стандартный значок; (13) хотя бы одна вещь нарисована под продукт; (14) эффект дозой и с причиной, прозрачность — только над живым содержимым; (15) понятно, что за экран и что сделать, кнопка называет результат; (16) образ и материал тянутся через поток; (17) место и компоновка собраны. Сначала определить полюс экрана — **«аккуратно без приёмов»** или **«смело»** (оба равноценны): для первого пункты 6–7 читаются как «лишнего нет», для второго — «приём один и системный». «Нет» по двум и более пунктам → вернуть. Значения из `good/` в находках не требовать — примеры не источник значений.
1е. **Логика эффектов** (Влад 04.10, `shared-taste/bad/11` — «эффекты без логики, нейрослоп») — сначала открыть STATE: есть ли запись «глубина со слоями · реф-опора · выбор Влада»? **Нет записи → любой градиент-свечение, глянец, внутренняя тень на экране = находка «вернуть»**, дальше пункты не нужны. Есть — по каждому градиенту, свечению, тени, глянцу на экране: (а) что он сообщает — слой выше, источник света, главный объект? нет ответа → убрать; (б) материал — это мир всего экрана или украшение одного-двух элементов на плоской странице? второе → вернуть; (в) громкий материал или главная кнопка повторяются в строках списка? → вернуть: в повторяющемся элементе всё тихое, главное действие — одно на экран или тихой ссылкой в строке; (г) сколько видов пилюль на экране — больше двух (тег и статус) → вернуть; (д) метрики одной анатомии, цвет числа только когда он значит статус.
1г. **Глубина как в рефе** (✓ Влад 03.10) — только если в паспорте направления «со слоями»: по каждой ключевой поверхности (стекло, плитка, главная кнопка) обходом узла посчитать слои — заливок, внутренних теней, есть ли кромка — и сравнить с рефом-опорой глазами в одном масштабе. Одна заливка там, где в рефе материал, — находка «вернуть» сборщику DS. Обратная проверка на грязь: > 3 материалов, разные источники света, тяжёлая серая внешняя тень — тоже находка. При направлении «плоско» находка — любой материал.
1ж. **Баланс по линзе Влада** (✓ Влад 04.10, `shared-taste` §0а: «экраны дополненные, не перегруженные, с дизайном и красивым визуалом») — по скриншоту ответить на Л1–Л8 с местом на экране и вывести баланс одним словом. Проверка **в обе стороны**: **скучно** (Л2 и Л7 «нет» — ни одного решения под продукт, всё дефолтное) → вернуть с подсказкой, где на экране место для одного хода (из §0 п. 13 и рефов проекта); **перегружено** (Л3 «нет» — ходов > 3, два громких фокуса, эффект без причины) → вернуть с тем, что убрать. «Норм» — только когда есть пол (Л1 + Л2) и не пробит потолок (Л3). Похожесть на `good/` не требовать: оценивается ход, не сходство. **Недобор проверяется отдельно** (✓ Влад 23.10, `shared-taste` §2б): если паспорт «строго / премиум», а в таблице инвентаря контраст кеглей < 3, акцентов 0, отступы равные, обводки на всём — это «вайрфрейм вместо премиума», вернуть с чек-листом наличия (контраст ≥ 4× · 1 акцент · волосяные линии · ритм 1:2:3 · один материал), не с «убрать».
1и. **Смысл данных и регистр** (✓ Влад 23.10, уроки Tenderflow): (а) **цвет = смысл** — красный / жёлтый / ⚠ только у того, что требует действия; факт (условия, сумма гарантии, срок) раскрашен как предупреждение — находка; (б) **одна первичная кнопка** на экран, остальные — один стиль второго уровня (три кнопки трёх стилей в шапке — находка); (в) **одна форма на сущность** — статус / таб / чип / бейдж не меняют форму внутри экрана; (г) **регистр от аудитории** — палитра и тон соответствуют тому, кто смотрит (тендерный менеджер ≠ жёлтый «стартап»; инвестор 50+ ≠ игровой): сверить с нишей §4.5 и паспортом, расхождение — находка до показа заказчику, не после; (д) **десктоп-сетка** — колонки на общей сетке, нижние кромки на одной линии, межколонные зазоры равны.
1к. **Три направления — одно на грани** (✓ Влад 23.10: «давай смелые решения» — прогресс только по команде): среди вариантов / направлений одно обязано быть «на грани перебора» (Л3 почти ✗), не третьим оттенком среднего; различимость — по разнице таблиц инвентаря (проход 0), не на глаз. Все три в одной зоне → вернуть с требованием смелого.
1з. **Чувство и механика** (✓ Влад 07.10, урок Tenderflow: 20 вариантов за 6 дней до P) — открыть строку «чувство · механика · данные» в брифе; по скриншоту: видна ли механика без пояснений, вызывает ли экран это чувство (у Tenderflow — «страшно упустить деньги»)? Нет → вернуть, даже если экран красивый и похож на реф. Если есть образ заказчика («как X / не Y») — не перекраска ли это того же каркаса вайрфрейма? Перекраска → вернуть с требованием раскладки без каркаса (`design-screen` 1в).
2. **Против вайрфрейма** (только состав, порядок, тексты, зоны — раскладка блока может и должна отличаться): скриншот утверждённого кадра рядом — порядок, состав, тексты, зоны нажатия совпадают? Любой дрейф без записи в «## Дизайн» — находка.
3. **Происхождение**: обход узлов (`use_figma`) — каждая заливка / обводка / отступ / радиус / текст привязаны к переменной или стилю; каждая используемая переменная есть в `tokens.json` с источником; `python3 design-tokens/tokens_check.py 03-design/tokens.json` — чисто. Значение вне токенов = находка.
4. **Контраст**: реальные пары на экране (текст / значок / граница на своей поверхности, включая текст на фото — по замеру `palette.py`) — AA (4.5 / 3 / 3). Цвет не единственный носитель — **но это не повод добавлять значок к выбранному**: заливка с заметной разницей по светлоте (выбранный тёмный / невыбранный светлый, ≥ 3:1 между ними) уже не «только цвет». Значок нужен, лишь когда состояния различаются одним оттенком при равной светлоте.
5. **Иврит / RTL / 50+**: **составные числа** — число + единица + дробь («1,240 / 1,800 ק״ל», «62 / 110 ג׳») собраны единым LTR-прогоном в одном текстовом узле или auto-layout-строке с фиксированным порядком, зум-скриншот: знак «/» и единица стоят с той стороны, с которой читаются (урок Squad 23.10: «/1,800 1,240»); **горизонтальный скролл** (чипы, карусель) начинается у правого края, обрезается слева (урок Squad: «‹» торчит слева, первый чип обрезан); начало строки, зеркалирование направленных иконок (зум-скриншот каждого шеврона и стрелки: «вперёд» — влево, «назад» — вправо; шеврон набран символом `‹ › < >` в ивритской строке — находка, даже если сейчас смотрит верно: двунаправленный алгоритм его отражает — урок Mayors 14.10), ₪ и числа, сжатый текст, основной ≥ 17, зоны ≥ 48, символ-статус приклеен к слову — запрещено.
6. **Система**: приёмы — в бюджете и применены одинаково; акцент не располз в хром; статусы по семьям STATE; образы подписаны, у каждого ответ «что сообщает».
7. **Только теперь** — раздел «## Дизайн»: доводы закрывают находки? Нет — находка остаётся.

## 2а. Варианты
Если вариантов несколько — каждый проходит 1–6; вариант «перекрашенный вайрфрейм», соломенный или с провалом AA / 50+ — отсеять (или вернуть) до Влада. Проверить, что варианты действительно разные (форма блоков, не цвет): **первые экраны различимы за 5 секунд**, верх экрана тоже расходится; хотя бы один вариант вне токенов (урок №1 v2, ✓ Влад). Дать свою рекомендацию с причиной.

## 4. Правила из правок Влада
