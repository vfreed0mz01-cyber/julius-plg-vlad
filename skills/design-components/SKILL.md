# Сборка дизайн-системы (Figma)

## 1. Когда и кто
После `design-tokens` (`tokens_check.py` чисто). Агент `ds-builder`; `figma-use` до первого `use_figma`. Пилотом — только нужное экрану-пилоту.

## 2. Где
Страница `Design System` в файле вайрфреймов проекта (нет → спросить Влада, затем создать). Секции: `Tokens / Color`, `Tokens / Type`, `Tokens / Space & Radius`, `Icons`, `Materials` (если есть), `Components`. Имена — английские; образцы текста — иврит. Отдельная библиотека — со второго проекта.

## 3. Переменные и стили
- Коллекции `Primitives` (шкалы) → `Semantic` (роли = алиасы на примитивы). Режим один (`Light`).
- `space/*`, `radius/*` — FLOAT-переменные.
- Text styles по ролям (`Body`, `Title`, `Amount/L` …); перед `loadFontAsync` проверить, что семейство и вес есть в среде. Шрифта нет → остановиться и сообщить лиду, **не подменять** (подмена = FONT в линте).
- Значения только из `tokens.json`; нужного токена нет → в отчёт токенисту, не придумывать.

## 3а. Материалы (паспорт «со слоями»)
- Паспорт «плоско» → раздел не применяется, материалов не заводить. Когда не применять и рецепты слоёв — `materials/recipes.md`.
- Материалы из `tokens.json` собираются **до компонентов**: стиль заливки `Material/<имя>` (несколько красок по порядку) + стиль эффектов `Material/<имя>` (+ обводка). Компонент берёт материал стилем целиком. Проверка: у узла с материалом ≥ 2 заливок или ≥ 1 внутренняя тень; одна SOLID-заливка = упрощение → находка.
- Нового материала нет в рецептах → собрать по строке «слои поверхности» из разбора рефа и дописать рецепт.
- Сдача: плитка каждого материала рядом с кропом рефа в одном масштабе, скриншотом.

## 4. Компоненты
- **Язык направления, не кит.** Кит `WF/*` даёт перечень компонентов, их данные и состояния; форма, поля, разделители, кегли — из паспорта направления и `refs.md`. Проверка: компонент с той же структурой слоёв и теми же отступами, что `WF/*`, — находка.
- Auto-layout везде; заливки, обводки, отступы, радиусы привязаны к переменным; текст — к стилям (линт UNBOUND).
- RTL: выравнивание по началу строки справа; иконки со смыслом направления — зеркальные варианты (разметка из `assets.md`).
- Зона нажатия ≥ параметра проекта из STATE (обычно 48), даже если видимая часть меньше.
- Иконки: SVG набора из `assets.md` → `figma.createNodeFromSvg` → `Icon/<name>` с вариантом `Weight`, цвет — переменная. Lucide запрещён.
- **Линейные образы без векторизации:** ч/б PNG → группа `Sketch`: `sketch/line` (цвет линий — переменная) → PNG `isMask = true`, `maskType = LUMINANCE` → `sketch/surface` (цвет поверхности — переменная). В RTL отражать PNG (`relativeTransform [[-1,0,w],[0,1,0]]`).
- Системные элементы iPhone (status bar, home, клавиатура) — компоненты Влада, id — STATE «Figma-узлы»; свои не рисовать.

## 5. Линт (перед сдачей)
Обход всех узлов страницы: (1) **UNBOUND** — заливка / обводка / отступ / радиус без привязки к переменной; (2) **STOCK COLOR** — значение ≈ стоковому (список — `design-tokens/tokens_check.py`); (3) **TEXT-SQUEEZE** — короткий лейбл порвался на 2+ строки (лечение — HUG / ширина, не кегль); (4) **FONT** — стиль не найден / подменён. Отчёт `LINT: чисто | N — список` прикладывается к отчёту.

## 6. Выход
Страница `Design System` (node id секций) · `03-design/components.md` (компонент · варианты · какой `WF/*` заменяет · токены) · скриншот каждой секции · отчёт лиду.

## 7. Границы
Не меняет значения токенов, не рисует экраны, не трогает кадры вайрфреймов и кит.
