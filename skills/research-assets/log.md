Lucide запрещён как дефолт (урок старого пака: «всё выглядит как шаблон»); любимого набора у Влада нет. v0.1 (30.09): уроки запуска Г Mayors (список по инстансам, штрих по TTF, «заливка для всех вкладок», Tabler ≈ Lucide, доска через Chrome headless, Unsplash браузером).

## 1. Зачем
Иконки и образы — то, что больше всего выдаёт «сгенерированный» дизайн: дефолтный набор иконок, фейковая геометрия вместо фото, 3D-декор рядом с суммой. Ресерч даёт Дизайну **выбор с обоснованием**: какой набор иконок согласуется со шрифтом и стилем, какие образы нужны продукту и что каждый сообщает.

## 2. Вход
- `02-research/visual/style.md` → «Базовый стиль ✓» (ось 8 «Иконки», ось 7 «Образы»).
- `02-research/visual/color-type.md` — шрифт-кандидат и его веса (штрих иконки подбирается к весу шрифта).
- **Список наших иконок** — со слотов кита в утверждённых кадрах, **собирать `use_figma` (только чтение) по инстансам**, а не по памяти / листам: обойти кадры (`findAll(n => n.type === "INSTANCE")`), взять `mainComponent.name` (`WF/Icon*`, `WF/Chevron*`, `WF/Stage marker`, `WF/Status icon`, `WF/Icon button`, слоты `Icon` в `WF/Status chip`, `WF/Button`, `WF/List row`, `WF/Task row`, `WF/File row`…), видимые (`visible`), смысл заглушки — из имени слоя / соседнего текста / описания компонента. + таббар, шапка, статусы. Обычно ~20–30 (Mayors — 27).
- `01-spec/model.md`, листы экранов — какие образы есть в контенте (фото объекта, ход стройки, агент, карта, лого, документы).
- Бриф — регистр, 50+ (подписи у нестандартных иконок), платформы (**есть веб → SF Symbols нельзя**), бренд заказчика; `spec-product-frame` — **правило декора**.
- `STATE.md` — решения Влада (например, «фото у недвижимости есть»).
- Фильтр источников — `research-visual-plan` §3.

## 4. Как решать

### 4.1 Иконки: кандидаты и критерии
**Не рассматривать:** Lucide как дефолт (запрет Влада); **SF Symbols** (лицензия — только платформы Apple, у нас веб); эмодзи вместо иконок.
**Осторожно:** Material Symbols — узнаваемо «гугловые», для iOS-продукта чужие; только если стиль близок.

Кандидаты (данные npm на 30.09.2026 — перепроверить лицензию на сайте на дату прогона):

| Набор | Лицензия | Стили | Объём | Заметка |
|---|---|---|---|---|
| **Phosphor** | MIT | thin / light / regular / bold / **fill** / duotone | 1512 в каждом стиле | контур и заливка **для каждой** иконки — удобно для активной вкладки; 6 весов под вес шрифта |
| **Tabler** | MIT | outline (штрих настраивается) / filled | 5166 контур / 1054 заливка | огромное покрытие; заливка есть не у всех; **геометрически двойник Lucide** (сетка 24, штрих 2, круглые концы) → тот же риск «шаблона», что у запрещённого Lucide — только с явной причиной |
| **Iconoir** | MIT | regular (штрих настраивается) / solid | 1383 / 288 | мягкий характер; заливок мало — проверить таббар |
| **Huge Icons** | бесплатный набор MIT (npm `@hugeicons/core-free-icons`); pro — платный | stroke rounded (free); pro — много стилей | — | проверить, что нужные иконки есть в бесплатном |
| Платные (Streamline, Central и др.) | лицензия | много стилей | — | только с согласия Влада / заказчика |

Критерии (по каждому кандидату, с числами):
1. **Штрих ↔ вес шрифта.** Штрих иконки должен совпадать со штрихом основного текста: примерно Regular 400 ↔ 1.5, Medium 500 ↔ 1.75–2, Light 300 ↔ 1–1.25 (на 24). **Мерить числами:** штрих шрифта — по TTF (`research-visual-anatomy/palette.py --font <ttf>` → «при 17 pt ≈ X pt»), штрих иконки — из SVG (`stroke-width` × размер / 24). Не по скриншоту. Итог — пара «иконка N на размере M = штрих шрифта в кегле K» (Mayors: Phosphor Regular 28 в таббаре = 1.75 ≈ Julius Medium 17). Затем проверить на доске рядом с подписью (§4.3).
2. **Концы и углы:** круглые / прямые концы, скругления углов — совпадают ли с радиусами и характером шрифта (геометрический гротеск ↔ прямые; округлый ↔ круглые).
3. **Контур + заливка для всех вкладок таббара** (и выбранных состояний) — критерий-отсев: активная вкладка = заливка, и если хоть у одной вкладки пары нет, её дорисовывают и набор теряет цельность. Считать «N / число вкладок» (Mayors: Phosphor 4 / 4, Tabler 3 / 4, Iconoir 0 / 4).
4. **Покрытие нашего списка:** N из M; для недостающих — ближайшая замена из набора или «рисовать» (в стиле набора).
5. **Лицензия:** коммерческое использование, атрибуция.
6. **Figma:** есть ли официальный плагин / community-файл; или вставка SVG (§4.3).
7. **Оптический размер:** держит ли 20 / 24 / 28 без размытия деталей (для 50+ иконки таббара ≥ 24).

### 4.2 Разметка RTL-зеркалирования
По каждой нашей иконке — колонка «RTL»:
- **Зеркалить** (направление = время / порядок чтения): назад / вперёд, шевроны, стрелки «перейти», отправить, выйти, отменить / повторить, список с маркерами, выравнивание текста, прогресс и шкалы, ось времени, «ответить».
- **Не зеркалить** (предметы и символы): часы, галочка, плюс, поиск, камера, телефон, замок, колокол, документ, дом, логотипы, цифры, медиа play / pause.
- Спорные — с пометкой: иконка, где рука / предмет «правой рукой», график со стрелкой роста. Основание — гайд двунаправленности Material (Bidirectionality) и конвенции израильских продуктов (проверить 1–2 живых).

### 4.3 Доска «наши иконки × наборы»
Строки — наши иконки (имя и слот), колонки — 2–3 набора; в каждой ячейке иконка 24 в нужном весе + **рядом подпись на иврите шрифтом проекта** основным кеглем (чтобы видеть штрих рядом с буквой); таббар — отдельной строкой в двух состояниях (контур / заливка). Внизу — отметка покрытия N из M и RTL-колонка.
**Как получить SVG:** скачать из npm-пакета через CDN (`curl`), например:
- Phosphor: `https://unpkg.com/@phosphor-icons/core/assets/regular/house.svg`, заливка — `assets/fill/house-fill.svg`;
- Tabler: `https://unpkg.com/@tabler/icons/icons/outline/home.svg`, `icons/filled/home.svg`;
- Iconoir: `https://unpkg.com/iconoir/icons/regular/home.svg`, `icons/solid/…` (заливок мало);
- дерево пакета: `https://unpkg.com/<пакет>/?meta`.
**Рендер доски:** HTML (SVG + подписи на иврите шрифтом проекта через `@font-face`, `dir="rtl"`) → **Chrome / Edge headless** `--headless=new --screenshot=<png> --force-device-scale-factor=2 --window-size=…` → Pillow обрезка. Браузер сам делает RTL и шейпинг иврита (Pillow без raqm переворачивает иврит). Генератор-образец: `projects/mayors/02-research/visual/assets/icons/gen_board.py`. PNG выше 4096 px — резать перед Figma (`research-visual-board` §4.4).
В Figma SVG вставляется **без загрузки картинок**: строкой в `use_figma` через `figma.createNodeFromSvg(svg)` (сеть внутри скрипта не нужна) или через `upload_assets` с `image/svg+xml` (импортируется как вектор). Имена слоёв — на английском (`Icon/Phosphor/house`).

### 4.4 Образы: слоты контента
Правило (Влад, 29.09): вайрфрейм сухой намеренно; на дизайне экран обогащается **образами из контента** — это содержание, не декор. У каждого образа — ответ «что он сообщает».

| Слот | Что сообщает | Пропорции / размер | Обработка | Заглушка (нет фото) | Откуда в продукте |
|---|---|---|---|---|---|
| Фото объекта | «это мой объект, узнаю его» | снять с рефов (например 350×160, 16:9, 4:3) | единая цветокоррекция, затемнение под текст ≥ 40% если на фото плашка | нейтральная плитка + значок типа объекта / инициалы проекта | застройщик / агент |
| Ход стройки | «стройка идёт, вот доказательство» | … | дата на фото | … | отчёты стройки |
| Лицо человека (агент, клиент, участник) | «у меня есть живой человек» | круг / скругление | один свет и цветокоррекция на всех лицах | **живое стоковое фото** под аудиторию (не инициалы на тоне — ✓ Влад 11.10) | профиль агента / пользователя |
| Карта | «где это» | … | приглушённая карта, одна метка | … | … |
| Лого застройщика | «кто строит» | … | монохром или оригинал? | название текстом | … |
| Превью документов | «какой это документ» | … | … | значок типа файла | загрузки |

- **Заглушка — плитка**, а не «геометрия-фейк» (случайные круги, градиенты, абстрактные дома): нейтральный тон поверхности + значок типа / инициалы. Заглушка должна держать тот же размер и радиус, что фото. **Исключение — люди:** **Люди — только живые фото** (Влад 11.10, `bad/12-initials-avatars.png`): аватар человека (агент, клиент, участник, отправитель сообщения) — настоящее фото лица, **не инициалы на однотонной заливке** и не силуэт. Источник — **пак плагина `${CLAUDE_PLUGIN_ROOT}/skills/research-assets/people/`** (20 лиц: м / ж, 25–75, деловые и повседневные; индекс и правила подбора — `README.md` там же); не хватает типажа — стоковые портреты (Unsplash / Pexels, бесплатная лицензия; Unsplash — через браузер, см. `research-assets`) или генерация (Figma `generate_image` / Higgsfield — только с согласия Влада, тратит кредиты); в Figma — через `upload_assets`. Подбор: возраст, пол, внешность — под аудиторию и регион проекта; в списке — разные лица; один свет и цветокоррекция; кадр «голова и плечи»; без знаменитостей. В макете для заказчика — пометка «фото-заглушка». Инициалы — только как отдельное состояние «у пользователя нет фото», не в основном кадре. Вайрфрейм — по-прежнему нейтральный круг `WF/Avatar` без букв.
- Пропорции и обработку **снимать с рефов** выбранного стиля (`refs.md`), с числами.
- **Для макетов:** 3–4 кандидата фото **реального места** проекта (Mayors — Дубай: башни, стройка, интерьеры off-plan) с Unsplash / Pexels — ссылка, автор, лицензия; скачать в `02-research/visual/assets/photos/`. **Unsplash — только через браузер** (поиск и страницы из скрипта / curl не отдаются; картинку потом качать по `images.unsplash.com…&w=…` со страницы), в **своей вкладке**, не в активной вкладке Влада; `premium / plus` проверить на странице (Unsplash+ — платный). Pexels — за антибот-проверкой, API по ключу. Не выдавать фото из интернета за объекты заказчика: в макете — пометка «фото-заглушка».
- **Иллюстрации / 3D / градиенты** — только по правилу декора (`spec-product-frame`): точечно в момент награды / гордости, онбординге, пустом состоянии; **не в рабочем потоке и не рядом с суммой**; в денежных продуктах момент гордости — тёплый акцент без конфетти. Если нужны — отдельный пункт «что рисовать и зачем», источник решает Дизайн (готовое / генерация / вектор в Figma).

## 6. Типичные провалы
- Lucide «по умолчанию» или набор из первого попавшегося шаблона.
- SF Symbols для продукта с вебом.
- Набор выбран без сравнения с весом шрифта — иконки жирнее или тоньше текста; штрих шрифта «на глаз» со скриншота, а не по TTF.
- Список иконок по памяти / листам, а не по инстансам кадров → половины слотов нет.
- Tabler взят «вместо Lucide» без оговорки — это та же геометрия.
- Подписи на иврите в доске, отрендеренные Pillow без RTL, — буквы задом наперёд.
- У таббара нет пары контур / заливка хотя бы у одной вкладки.
- Покрытие не проверено: половину иконок потом рисуют «на коленке» в другом стиле.
- Зеркалятся все иконки подряд (часы, галочка) — или ни одной (стрелка «назад» смотрит не туда).
- Заглушка фото — фейковая геометрия или градиент.
- Стоковое фото подано как объект заказчика.
- 3D / иллюстрация рядом с суммой или в рабочем потоке.
