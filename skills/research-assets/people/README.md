# Пак лиц для макетов (20 портретов)

Аватары людей в дизайне — только живые фото, не инициалы на однотонной заливке (`shared-taste/bad/12-initials-avatars.png`).

- Формат: JPG 400×400, кадр по лицу (`crop=faces`), под круг / скругление. Для аватара 48 px этого хватает с запасом (×3 = 144).
- Источник: Unsplash, [лицензия Unsplash](https://unsplash.com/license) — бесплатно, в т.ч. коммерчески, без атрибуции; нельзя продавать фото как есть. В макете для заказчика — пометка «фото-заглушка».
- В Figma — через `upload_assets` (`createImageAsync` не работает), заливка `FILL`.
- Подбор: роль на экране (агент — деловые портреты, клиент / участник — повседневные), возраст под аудиторию проекта (50+ — `p01`, `p02`, `p11`, `p12`, `p13`, `p14`), в одном списке — разные лица, не повторять одно лицо на разных ролях одного экрана.
- Не хватает типажа (ребёнок, конкретная внешность региона) — докачать с Unsplash по тем же правилам и дописать сюда строку.
