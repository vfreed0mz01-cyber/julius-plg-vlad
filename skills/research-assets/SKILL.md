# Ассеты (В6)

Поиск, источники, картинки, вставка в Figma — `shared-research-howto`. Генератор доски иконок — `gen_board.py` рядом. Пак лиц и правила подбора — `people/README.md`. История — `log.md`.

## 1. Вход
- `style.md` → «Базовый стиль ✓» (оси 7 «Образы», 8 «Иконки»). `color-type.md` — шрифт-кандидат, веса, штрих по TTF.
- **Список иконок — `use_figma` (чтение) по инстансам утверждённых кадров**: `findAll(n => n.type === "INSTANCE")` → `mainComponent.name` (`WF/Icon*`, `WF/Chevron*`, `WF/Stage marker`, `WF/Status icon`, `WF/Icon button`, слоты `Icon` в `WF/Status chip`, `WF/Button`, `WF/List row`…), только `visible`; смысл — из имени слоя / соседнего текста / описания компонента; плюс таббар, шапка, статусы. Обычно 20–30. Проверка: число строк = число уникальных слотов по инстансам, не по памяти.
- `model.md`, листы экранов — какие образы есть в контенте. Бриф — регистр, 50+ (подписи у нестандартных иконок), платформы (**веб → SF Symbols нельзя**), бренд; `spec-product-frame` — правило декора. STATE — решения Влада.

## 2. Иконки: кандидаты и критерии
**Не рассматривать**: Lucide как дефолт; SF Symbols при вебе; эмодзи. **С оговоркой**: Material Symbols («гугловые»); Tabler — геометрический двойник Lucide (сетка 24, штрих 2, круглые концы) — только с записанной причиной.

| Набор | Лицензия | Стили | Заметка |
|---|---|---|---|
| **Phosphor** | MIT | thin / light / regular / bold / fill / duotone | контур + заливка для каждой; 6 весов под вес шрифта |
| **Tabler** | MIT | outline (штрих настраивается) / filled | большое покрытие; заливка не у всех; двойник Lucide |
| **Iconoir** | MIT | regular / solid | мягкий характер; заливок мало — проверить таббар |
| **Huge Icons** | free MIT (`@hugeicons/core-free-icons`); pro платный | stroke rounded | проверить, что нужные есть в бесплатном |
| Платные (Streamline, Central…) | лицензия | много | только с согласия Влада / заказчика |

Лицензию перепроверять на сайте на дату прогона. Критерии по каждому кандидату, с числами:
0. **Заливка по умолчанию** (✓ Влад 07.11): навигация и таббар — сплошные глифы в духе SF; у кандидата должен быть filled-вариант всего списка. Контурный набор — только по паспорту направления.
1. **Штрих ↔ вес шрифта** (для контурных): штрих шрифта — по TTF (`research-visual-anatomy/palette.py --font` → «при 17 pt ≈ X»), иконки — из SVG (`stroke-width` × размер / 24), не по скриншоту. Итог — пара «иконка N на размере M = штрих шрифта в кегле K» (пример: Phosphor Regular 28 в таббаре = 1.75 ≈ Medium 17).
2. **Концы и углы** совпадают с радиусами и характером шрифта (геометрический ↔ прямые; округлый ↔ круглые).
3. **Контур + заливка для всех вкладок таббара** — отсев: «N / число вкладок»; меньше полного — набор теряет цельность.
4. **Покрытие** N из M; недостающие → замена из набора или «рисовать в стиле набора».
5. **Лицензия** (коммерческое, атрибуция). 6. **Figma** (плагин / community-файл / SVG). 7. **Оптический размер** 20 / 24 / 28 без размытия.

## 3. Разметка RTL
Колонка «RTL» у каждой иконки: **зеркалить** — направление = время / порядок чтения (назад / вперёд, шевроны, отправить, выйти, отменить / повторить, прогресс, ось времени); **не зеркалить** — предметы и символы (часы, галочка, плюс, поиск, замок, документ, дом, лого, цифры, play / pause); **спорные** с пометкой (предмет «правой рукой», график со стрелкой) — по гайду Material Bidirectionality и 1–2 живым израильским продуктам.

## 4. Доска «наши иконки × наборы»
Строки — иконки (имя, слот), колонки — наборы; в ячейке иконка 24 в нужном весе + **подпись на иврите шрифтом проекта** основным кеглем; таббар отдельной строкой в двух состояниях; внизу — покрытие N из M и колонка RTL.
- SVG из npm через CDN (`https://unpkg.com/<пакет>/?meta` — дерево): Phosphor `@phosphor-icons/core/assets/regular/house.svg` (`fill/house-fill.svg`); Tabler `@tabler/icons/icons/outline/home.svg` (`filled/`); Iconoir `iconoir/icons/regular/home.svg` (`solid/`).
- Рендер: `gen_board.py` (HTML с `@font-face`, `dir="rtl"` → Chrome / Edge headless `--headless=new --screenshot --force-device-scale-factor=2` → Pillow обрезка); в копии под проект поправить `FONT` и `map.json`. Проверка: первая буква подписи справа (Pillow без raqm переворачивает иврит). PNG > 4096 px — резать.
- В Figma SVG — `figma.createNodeFromSvg(svg)` или `upload_assets` с `image/svg+xml`; слои `Icon/<набор>/<имя>`.

## 5. Образы: слоты контента
Вайрфрейм сухой намеренно; на дизайне экран обогащается образами **из контента** — у каждого ответ «что сообщает».

| Слот | Что сообщает | Пропорции / обработка | Заглушка (нет фото) | Откуда |
|---|---|---|---|---|
| Фото объекта | «это мой объект» | с рефов (например 350×160, 16:9); единая цветокоррекция; затемнение ≥ 40 % под плашку с текстом | нейтральная плитка + значок типа / инициалы объекта | заказчик |
| Ход работ | «идёт, вот доказательство» | дата на фото | плитка | отчёты |
| Человек | «есть живой человек» | круг / скругление; один свет на всех лицах | **живое фото из `people/`**, не инициалы | профиль |
| Карта | «где это» | приглушённая, одна метка | плитка | — |
| Лого партнёра | «кто» | монохром или оригинал | название текстом | — |
| Превью документа | «какой документ» | — | значок типа файла | загрузки |

- **Заглушка — плитка** того же размера и радиуса, что фото; не «геометрия-фейк» (случайные круги, градиенты, абстрактные дома).
- **Люди — только живые фото**: пак `${CLAUDE_PLUGIN_ROOT}/skills/research-assets/people/` (20 лиц, подбор — README); нет типажа → Unsplash / Pexels; генерация — только с согласия Влада. Инициалы — только как состояние «нет фото». Проверка: в основном кадре нет аватара-инициалов и силуэтов. В макете для заказчика — пометка «фото-заглушка».
- Пропорции и обработку снимать с рефов стиля (`refs.md`), с числами.
- **Фото для макетов**: 3–4 кандидата реального места проекта (Unsplash / Pexels; Pexels — API по ключу) — ссылка, автор, лицензия; в `02-research/visual/assets/photos/`. За объекты заказчика не выдавать.
- **Иллюстрации / 3D / градиенты** — только по правилу декора (`spec-product-frame`): награда, онбординг, пустое состояние; не в рабочем потоке и не рядом с суммой. Нужны → пункт «что рисовать и зачем», источник решает Дизайн.

## 6. Формат выхода
`02-research/visual/assets.md`:
```
# Ассеты: <проект> · базовый стиль <…>
## Наш список иконок      | # | Иконка | Слот | Экраны | Смысл | Активное состояние? | RTL |
## Наборы-кандидаты       ### И1 <набор> — лицензия · стили · штрих ↔ вес · концы · контур + заливка N/вкладок · покрытие N/M · Figma · недостающие → замена
## Рекомендация (набор + вес + причина)
## Образы: слоты          | Слот | Что сообщает | Пропорции | Обработка | Заглушка | Источник | Рефы (ID) |
## Фото для макетов       | ID | Что на фото | Ссылка | Автор | Лицензия | Файл |
## Иллюстрации / 3D (только по правилу декора)
```
SVG: `assets/icons/<набор>/`; фото: `assets/photos/`. На доску — секция 7.
