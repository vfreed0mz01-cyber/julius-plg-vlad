# Case — презентация решения

## 1. Когда и кто
В конце проекта или этапа, только по слову Влада. Агент `visual-designer` (запуск «Case»); айдентика — из `brand.md` и страницы `Brand`, если этап был. Страница `Case` в Figma-файле проекта, ширина 1440; перед созданием — спросить Влада, нет ли уже.

## 2. Вход
STATE, рамка и бриф, `niche.md`, `navigation.md` (шаги до главной задачи), утверждённые экраны (node id), `brand.md`, `04-critic/` (что исправлено — для «было → стало»).

## 3. Разделы (сверху вниз)
1. **Hero:** название крупно, строка «что это», метки «платформа · тип работы · год» мелко; справа — главный экран или образ продукта (не абстракция).
2. **Задача — числом:** «было N шагов → стало M» (из `navigation.md`) или другой проверяемый показатель из рамки. Задача без числа → находка.
3. **Роль:** 3–6 плиток «что делали».
4. **Ресерч — нарисованный:** конкуренты таблицей точками, паттерны 3–4 картинки с подписью, функции капсулами.
5. **Решения — по одному на раздел:** метка цветом бренда → заголовок 2–3 строки → текст ≤ 4 строк → крупный экран; сторона экрана и текста чередуется.
6. **Айдентика — тёмной вставкой:** знак, шрифт образцом («AaBbCc» + цифры), цвета формой бренда, элемент и паттерн, 2–3 кадра примерки.
7. **Результат:** было → стало числами, решения Влада одной строкой, что дальше.

## 4. Правила раскладки
- Одна сетка на страницу: метка слева (~25 %), текст справа (~60 %); колонки не меняются сверху донизу.
- Воздух между разделами = 2–3 × внутреннего (160–200 / 24–48); разделяют отступ и тон, не линии.
- Ритм фона: светлые разделы — процесс, тёмная вставка — айдентика.
- Один мотив из формы знака / продукта, повторён 2–4 раза, не на каждом разделе.
- Ритм картинок: широкая → две узкие → во всю ширину; подряд одна сетка карточек → находка.
- Экраны крупно, современными мокапами (интерфейс читается при 100 %); фото ч/б или в палитре бренда.
- Текст: абзац ≤ 4 строк; цитаты ≤ 2 строк; кегль метки и текста в одной шкале с размером блока (мелкий текст у огромного блока → находка). Значки — свой набор, эмодзи = находка.
- Линза `shared-taste` §0 на всю страницу: баланс «норм».
