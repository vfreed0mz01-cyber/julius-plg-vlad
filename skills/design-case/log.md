# Case — презентация решения

> v0 (2026-10-06, ✓ Влад: «да, всё делай как рекомендуешь»). Устройство взято из страниц-кейсов Purrweb (EvTrip, Shaoke) — разбор `shared-taste` `good-41`, `good-42`.

## 1. Когда и кто
- В конце проекта или крупного этапа, **только по слову Влада**. Рабочие доски (`Research`, `Design System`) — для работы; Case — для показа.
- Агент `visual-designer` (запуск «Case»); если был этап бренда — айдентику берёт из `brand.md` и страницы `Brand`.
- Где: страница `Case` в Figma-файле проекта (ширина 1440, веб-раскладка); перед созданием — спросить Влада, нет ли уже.

## 2. Вход
STATE (решения Влада), рамка продукта и бриф, `niche.md`, `navigation.md` (шаги до главной задачи), утверждённые экраны (node id), `brand.md` если есть, `04-critic/` (что было исправлено — для «было → стало»).

## 3. Разделы (сверху вниз)
1. **Hero:** название продукта крупно, одна строка «что это», метки «платформа · тип работы · год» мелко; справа — главный экран или образ продукта. Фото / экран, а не абстракция.
2. **Задача — с числом.** «Чтобы решить главную задачу, нужно было пройти N шагов» → стало M (из `navigation.md`); или другой проверяемый показатель из рамки.
3. **Роль:** 3–6 плиток «что делали» (ресерч, архитектура, айдентика, дизайн…).
4. **Ресерч — нарисованный:** конкуренты таблицей точками (есть / нет), паттерны — 3–4 картинки с подписью; главные функции — капсулами.
5. **Решения — по одному на раздел:** метка цветом бренда (маркер под словом) → заголовок 2–3 строки → текст ≤ 4 строк → крупный экран; сторона экрана и текста чередуется.
6. **Айдентика / система — тёмной вставкой:** знак, шрифт образцом («AaBbCc» + цифры), цвета формой бренда (капсулы, если капсула — элемент знака), фирменный элемент и паттерн, 2–3 кадра примерки.
7. **Результат:** было → стало числами, решения Влада одной строкой, что дальше.

## 4. Правила раскладки
- **Одна сетка на всю страницу:** метка раздела слева (колонка ~25 %), текст справа (~60 %); колонки одни и те же сверху донизу.
- **Воздух между разделами в 2–3 раза больше, чем внутри** (например 160–200 между, 24–48 внутри); разделяют отступ и тон фона, не линии.
- Ритм фона: светлые разделы — процесс, тёмная вставка — айдентика / главная глава.
- **Один мотив страницы — из формы знака / продукта** (кольца, капсула, полоса), повторён 2–4 раза, не на каждом разделе.
- Ритм размеров картинок: широкая → две узкие → во всю ширину; не одна сетка карточек подряд.
- Экраны — крупно и современными мокапами (интерфейс должен читаться); фото — ч/б или в палитре бренда.
- Линза `shared-taste` §0а на всю страницу: баланс «норм».

## 5. Типичные провалы
- Эмодзи вместо значков; стоковые иллюстрации; мелкие старые мокапы, где не разглядеть интерфейс.
- Абзацы по 8–10 строк; курсивные цитаты длинным текстом.
- Мелкий текст рядом с огромными блоками — масштабы не связаны.
- Задача без числа («сделали удобнее»); результат без «было → стало».
- Каждый раздел своим приёмом — нет одного мотива и одной сетки.
