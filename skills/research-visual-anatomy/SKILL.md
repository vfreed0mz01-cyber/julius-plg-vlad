# Цвет и типографика (В5)

Поиск, источники, картинки — `shared-research-howto`. Скрипты рядом: `palette.py` (Pillow; все опции и примеры — `python palette.py --help`), `rtl.py` (образцы на иврите). История, данные шрифта проекта, примеры — `log.md`.

## 1. Граница
Ресерч **измеряет** числами с рефов выбранного стиля; палитру (OKLCH-шкалы, свои hex), шкалу и токены строит Дизайн. AA (4.5 / 3 / 3) — пол. Цвет — не единственный носитель смысла. Проверка: в `color-type.md` нет hex, которого нет на рефе.

## 2. Вход
- `style.md` → «Базовый стиль ✓»; `refs.md` — экраны «страница» и «детали» (их и мерить). Полные картинки `crops/src/*` (@3x), не превью.
- STATE — шрифт проекта (веса и глифы проверять `--font`, не по памяти), решения по статусам. Бриф — 50+, RTL, бренд заказчика (его цвета и шрифты приоритетнее). `model.md` — максимальные суммы, длинные названия, смешанные строки.

## 3. Цвет — скриптом
Hex «на глаз» не пишется. Координаты (`--crop`, `--exclude`, `--pick`, `--scan-*`, `--text`) — в pt исходника. Windows: `set PYTHONIOENCODING=utf-8`.
```bash
python palette.py crops/src/S1-3.webp --mobbin --json anatomy/S1-3.json   # полный анализ, полоса Mobbin отрезана
python palette.py shot.png --pick 40,212 --scan-row 212 --text 16,120,300,60   # точка, отрезки, текстовый блок
python palette.py --font <ttf>          # глифы, табличные цифры, кернинг (fontTools), штрих по весам
python palette.py --pair "#6B6B6B" "#F4F1EC"
```
**Как читать честно**
- Кластеры — эвристика. «Возможно сглаживание» = серый между текстом и фоном → `--pick` на толстом штрихе.
- WebP / JPG: hex плавает на 1–3; «ореолы» у цветных кнопок (доля < 0.1 %) — не цвет системы. Ключевые цвета перепроверить `--pick` на плоской области.
- «Акцент-кандидат» — самый частый хроматический цвет; что это (кнопка, статус, ссылка) — по местам.
- Автопоиск фото достраивает до прямоугольника; небо / вода у края попадают в «акцент» → пометку «небо / вода?» проверять; сомнение → `--exclude` фото целиком. Иллюстрации из плоских цветов → `--exclude`, если искажают доли.
- Контраст текста — только `--text` по блоку, не строка «прочие цвета».
- Статусы: по местам назвать, какой цвет какой статус; записать тон текста, подложку, контраст к подложке.

Снять на 4–6 экранах (+ детали): поверхности (hex, OKLCH, доля, где) · нейтрали (ступени, тёплые / холодные, контраст каждого текста к фону) · акцент (какой, места, число) · статусы · доли без фото (светлые / тёмные / хроматика) · тёмные зоны · носитель смысла кроме цвета. **Сводка по стилю** — что повторяется («фон тёплый ≈ OKLCH L 96 %, C 0.007; один акцент в 5 из 6; статусы тоном текста») — вход для Дизайна.

## 4. Типографика
1. **Класс гарнитуры рефа** — по форме (a, g, R, цифры 1 / 4 / 7) или названию.
2. **2–3 ивритских аналога без засечек.** Кандидат № 1 — шрифт проекта, если подходит по классу и весам. Свободные (проверять на дату): Heebo, Assistant, Rubik, Noto Sans Hebrew, IBM Plex Sans Hebrew, Open Sans, Varela Round, Secular One (только заголовки); платные — «нужна лицензия».
3. Таблица проверки **по файлу** (`--font <ttf>`; без `fontTools` — только штрих):

| Шрифт | Класс | Веса | Цифры (табличные?) | Латиница | ₪ | Есть в Figma | Замечание |
|---|---|---|---|---|---|---|---|

- Штрих — по TTF, не по скриншоту; у вариативного партнёра штрих по весам 100–900 → вес партнёра подбирается по штриху к весам шрифта проекта. Этот штрих — вход для иконок (`research-assets` §2).
- Нет латиницы / ₪ → назвать **пару** и на сколько % подогнать кегль по высоте (§7).
- Образцы на иврите — Pillow через `rtl.py` (логический порядок, LTR-группы `{'ltr': [...]}`, партнёр для недостающих знаков, шрифты через `rtl.font()`). Проверка PNG: первая буква иврита справа, цифры слева направо.

## 5. Шкала уровней
Кегль ≈ высота цифр / заглавных ÷ 0.7 (pt); высота строки = шаг базовых (`--text`). Системный шрифт iOS → сверить со шкалой (Large Title 34, Title 1 28, Title 2 22, Title 3 20, Headline 17 semibold, Body 17, Callout 16, Subheadline 15, Footnote 13, Caption 12 / 11), писать точное значение.

| Уровень | Кегль | Строка | Вес | Трекинг | Где у рефа |
|---|---|---|---|---|---|
| Крупное число · Заголовок экрана · секции · карточки · Основной · Вторичный · Подпись | | | | | |

Плюс соотношения (крупное / основной, заголовок / основной), число весов, чем создаётся иерархия. Размеры не увеличивать «для 50+» (50+ = понятность, P15); сверять с нормой платформы.

## 6. Заголовки
Таблицей по рефам: **где** (шапка / контент; край начала строки / центр) · **отступы** сверху и снизу (сверху > снизу, P4) и от края · **прокрутка** (сворачивается в шапку / остаётся / уезжает; разделитель) · **макс. строк** и что с длинным · **КАПС-метки** → чем заменить в иврите (вес + кегль + цвет; разрядку проверить на шрифте проекта) · соседство с крупным числом (одинаковый кегль и вес → фокус теряется, фиксировать).

## 7. Суммы и ₪
- Кегль знака относительно числа (равный / 60–75 %), вес, отступ, позиция — снять у **израильских продуктов** (банки, Bit), источник в таблице обязателен.
- Табличные цифры в колонках сумм — у рефа и у кандидатов. Суммы и даты в RTL-строке — LTR-изоляция.
- **Высота**: отношение высоты ивритских букв к цифрам / заглавным у кандидата и пары; на сколько % подогнать кегль латиницы / цифр.

## 8. Формат выхода
`02-research/visual/color-type.md`:
```
# Цвет и типографика: <проект> · базовый стиль <…>
## Цвет — по экранам      ### С1-3 <продукт — экран> (anatomy/S1-3.json): поверхности · нейтрали и контраст · акцент и места · статусы · доли без фото · тёмные зоны
## Цвет — сводка по стилю
## Типографика: класс и ивритские аналоги (таблица) · шкала уровней · заголовки · суммы и ₪ · высота иврита vs латиница и цифры
## Что передаём Дизайну (измерено) / что решает Дизайн
```
`anatomy/<ID латиницей>.json` — сырой `--json`. На доску (секция 6) — образцы цвета с hex и контрастом, лестница шкалы на иврите.
