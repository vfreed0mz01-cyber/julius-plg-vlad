# Вкус Влада

Вкус автора, не правило проекта: решения по проекту (бренд, стиль, образ заказчика) — в STATE, они важнее. Полюса равноценны: «аккуратно без приёмов» (`good-02`, `-11`, `-20`), «смело» (`good-06`, `-17`, `-37`), «тихо» (`good-22`, `-36`) — какой, решает проект. `good/` — образцы хода, не источник значений.

## 0. Линза Л1–Л8 — как смотреть на любой экран или реф (бывшие §0 + §0а)

| Л | Вопрос | «Да» выглядит так | Проверка | good |
|---|---|---|---|---|
| Л1 | Что за экран и что важное? | одна ось: образ → главное → почему → действие; кнопка называет результат | тест 5 с: что за экран · главное · что сделать — три ответа; глаз первым идёт к герою из карты | `27`, `32`, `38` |
| Л2 | Чувствуется, что есть дизайн? | ≥ 1 вещь нарисована под продукт (шкала-капсула, ползунок-клин, облегающий контейнер) | ≥ 1 элемент под продукт назван в карте композиции («Приём 1») | `27`, `28`, `33`, `37e` |
| Л3 | Не выедает глаз? | смелость в 1–3 местах (форма блока, фон, материал), остальное тихое; стекло — над живым, свечение — за одним объектом | ходов ≤ 3; громкий фокус 1; у эффекта строка «что сообщает / откуда свет» | `01`, `21`, `35`; `bad/11` |
| Л4 | Воздух и место? | карточка от фона — тоном, обводка волосяная; пустота собрана вокруг группы с опорой внизу; картинка занимает место, текст встаёт рядом; диагональ вместо центра | `void_pct`, `blank_gap` в порогах инвентаря; «рамка в рамке» = 0; тень только у слоя выше | `11`, `23`, `26e`, `37`, `40` |
| Л5 | Иерархия? | размер и вес, не цвет; числа главные; «подпись мелко / значение крупно»; заголовок экрана и ведущие суммы — размер и вес по рефам / донору (свобода: и Bold, и Light) | `lead_ratio` ≥ 1.3 (премиум 1.6); герой / основной ≥ 1,8 (премиум мобайл 2,5, десктоп 4); веса ≤ 3 (третий — у заголовка / сумм, по рефам); подписи тихие (≤ ⅓ кегля значения) | `02`, `10`, `12`, `38` |
| Л6 | Цвет и акценты? | 3–4 цвета, у каждого одна роль; цвет снят с объекта / образа; вторичный текст — ступень основного, не серый | цветов ≤ 4; акцент ≤ 3 мест и значит одно; в карте «откуда цвет: объект / образ / бренд»; статус — цвет один раз | `01`, `03`, `13`, `34`, `35` |
| Л7 | Образ / визуализация? | образ несёт смысл или данные; набор одной руки в палитре; фото / карта приглушены; данные — материалом интерфейса (шкала отрезками, оси) | у образа ответ «что сообщает»; один набор на продукт; образ ≥ 2 раз в потоке разным масштабом; кольцо без единиц / волна без осей = 0 | `08`, `14`, `22`, `35e`, `39` |
| Л8 | Аккуратно? | одна шкала радиусов, один материал, иконки одного набора без подложек (по умолчанию сплошные), навигация тихая (активный пункт — отметкой) | радиус = тип элемента; веса ≤ 3; иконки одного набора (у контурных штрих = вес шрифта); активный пункт не залит акцентом; кропы @2x чистые (`critic-design` §2) | `02`, `05`, `20`, `24` |

**Баланс:** **скучно** — Л2 ✗ и Л7 ✗ · **норм** · **перегружено** — Л3 ✗ (ходов > 3, два фокуса, эффект без причины). Пол — Л1 + Л2, потолок — Л3.

**Пять диагнозов** (из Stageshow, ✓ Влад 07.11). Любое «вернуть» и любая самопроверка называют диагноз по имени и место на экране:

| Диагноз | Как выглядит | Проверка | Лечение |
|---|---|---|---|
| **перегружено** | слов, чисел, пилюль, эффектов везде; чем больше деталей, тем больше похоже на сгенерированное | Л3 ✗; теллы 13, 14, 17; `accent_hues`, `shadow_nodes` ✗ | убрать: один громкий фокус, остальное тихое; ходов ≤ 3 |
| **вайрфрейм** | серые боксы и кнопка, вычищено то, что делало продукт узнаваемым | Л2 ✗; телл 28; `void_pct`, `blank_gap`, `lead_ratio` ✗ | добавить по чек-листу наличия (телл 28), не «ещё убрать» |
| **в коробке** | экран из одинаковых коробок с ровными полями: блок вставлен скриншотом, а не встроен в экран | теллы 11, 12; `clone_siblings`, `double_dress` ✗ | снять коробку: форма по содержанию (строки, линия, тон), одиночный элемент — без плитки |
| **плоско** | всё одного веса в одинаковых рамках, глазу некуда сесть | Л5 ✗; теллы 3, 5, 20; `size_contrast`, `heroes` ✗; тест 5 с без героя | один герой, ритм размеров 1:2:3, ведущая цифра ≥ 1,6× |
| **пресно** | экран мог бы быть любым продуктом: образ заказчика, регистр и паспорт не прочитаны | Л7 ✗; reflex-check (в) = (а); чувство из брифа не видно | один ход под продукт из образа заказчика / паспорта (Л2), не декор |

Диагноз не привязан к балансу (в коробке бывает и скучно, и перегружено): возврат лечится по колонке «Лечение» своего диагноза; два диагноза — оба лечения.

**Как записывать:** `Линза: Л1 ✓ (вердикт крупно в центре) · Л2 ✓ (шкала-капсула) · Л3 ✗ (свечение у трёх карточек) … → баланс: перегружено`. Место на экране обязательно; «красиво» без места не принимается.

## 2. Теллы — что выдаёт слоп / дефолт / ИИ (один список; телл → замена)
Собрано 23.10 из пяти списков (§2 «паттерны плохого», «грязный дизайн», «нейрослоп», «ИИ-признаки мобайла», §2 «дефолты-автопилота») — оригиналы с цитатами в `taste-log.md` §2. **Каждый пункт проверяем**: критик и карта композиции отвечают «нет | есть, потому что …»; «есть» без причины из задачи пользователя / STATE / образа заказчика — находка. Не запрет навсегда — запрет без обоснования.

**Композиция и автопилот**
1. Приветствие с именем крупно наверху («צהריים טובים, נועה») → убрать, 13–15 серым, или герой.
2. Перекрашенный вайрфрейм (та же раскладка + цвет) → таблица перевода, другая форма блоков.
3. Лента блоков одного веса / карточки-клоны ≥ 3 подряд / «12 виджетов дерутся» → один герой, список строками, ритм размеров.
4. Два героя (объект сверху + он же в карточке / 3D в таббаре; две крупные цифры) → один; второй — иконкой / строкой.
5. Три KPI в ряд «число / מתוך N» одной анатомии как единственная подача данных → ведущая цифра ≥ 1.3×, остальные тише.
6. Карточка персоны (аватар 80 + имя + роль + кнопка) для «вашего агента»; фото человека в углу шапки (= мой профиль) → подписанная строка с действием словом.
7. Дисклеймер-сирота над таббаром; «הכל» одинаково у каждой секции; «•••» без содержимого → убрать или дать содержание.
8. Приём без содержания (цветная зона / наезд / вырез, в котором нет ничего, чего нет снаружи) → вопрос «что здесь, чего нет снаружи?»; нет ответа — убрать.
9. Метафора буквально (пиктограмма-здание, «батарейка»-этажи) → через композицию и типографику.
10. Бенто-сетка как стиль; «как в Google Stitch» (градиенты + тяжёлые тени + пилюли + общие иконки) → один приём, одна шкала.

**Поверхность и цвет**
11. Серый фон + белые карточки r20–24, **каждая сущность в своей карточке** + плашка в плашке как язык экрана («ИИ-дашборд 2024–26») → белый фон, волосяные линии, строки. **Не телл:** сгруппированный список iOS (inset grouped) — одна белая плашка на смысловую группу на светло-сером фоне, внутри строки через линию (✓ Влад 07.11, сравнение со Stageshow).
12. Карточка в карточке; рамки в рамках; цветная полоса по краю карточки → тон и воздух.
13. Тень + обводка на одном узле; тяжёлая серая тень у каждого блока; тени / градиенты / свечение / стекло разом → либо тон, либо волосяная обводка; эффект только по паспорту «со слоями» и с ответом «что сообщает / откуда свет».
14. Громкий материал или главная кнопка в каждой строке списка → в повторяющемся элементе всё тихое, первичная кнопка одна.
15. Светофор: один цвет = много смыслов, или один смысл пятью способами (рамка + полоса + фон + текст + значок); факт раскрашен как предупреждение → цвет один раз, цвет = действие / статус по семьям STATE.
16. Клише «премиума»: золото, оранжевый градиент на синем, крем + терракот, мутные лиловые подложки; кремовый фон «не очень»; дефолтный градиент синий → фиолетовый → цвет от объекта / образа, градиент внутри одного цвета.
17. Пилюли, бейджи, мелкие подписи горой; пилюля с точкой + текстом + рамкой; пять видов пилюль на экране; капсула в капсуле (сумма в пилюле внутри кнопки, чип без причины) → ≤ 2 вида, цвет статуса один раз, одна форма на сущность.
18. Галочка / статус в каждой строке, когда он у всех одинаковый; галочка в уже залитом чипе; символ-статус у слова («מושכר ✓»); бейдж-статус на кружке аватара → одно состояние — один сигнал; статус словом в строке.
19. Текстура, зерно, «блобы», эмбиент без смысла → только на сцене, под контролем (≈ 1 pt, ≈ 1 %), не на карточках.

**Типографика, иконки, система**
20. Всё одного веса или всё жирное; четыре веса; «жирный + серый подзаголовок» пятый раз подряд; центр и правый край вперемешку; висячие слова → 2 веса в тексте (третий — у заголовка и сумм, если так у рефов), контраст кеглей ≥ 3 (премиум ≥ 4), третий повтор меняет форму.
21. Скругления разнобоем (пилюля среди острых, один тип элемента с разными углами); огромные скругления на всём → радиус = тип элемента.
22. Иконки «просто вставлены»: Lucide / общие наборы, коллажи метафор (щит + замок + галочка), иконка в бледном кружке у каждого пункта, стандартный значок на главной кнопке → иконки — часть стиля: **по умолчанию сплошные глифы в духе SF** (таббар, навигация, знаки-смыслы), контурные — только по паспорту направления (у контурных штрих = вес шрифта); в B2B иконок в кружках 0 (✓ Влад 07.11).
23. Библиотека как есть (shadcn / Material / Tailwind: тумблеры, инпуты, пилюли, палитра, радиусы) → токены с источником; стоковые hex — STOCK.
24. Декор, притворяющийся данными: кольца без единиц, графики-волны без осей, легенда не из системы, фейковые графики и «идеальные» числа (99.99 %, 1 000 000), нумерация «01 / 02» и декоративные точки, «John Doe» / «elevate» → данные материалом интерфейса (шкала отрезками, оси, серое сравнение), живые числа и тексты. Сюда же (✓ Влад 23.11, ticitaca): **стопка-призрак** — пустые карточки за карточкой, которые ничего не считают; **дорожка к точке** без прогресса; плавающая карточка-уведомление в hero, повторяющая данные ниже → стопка из настоящих объектов по их числу (сверху главный, края следующих). Стопка, ряд точек, линии как приём не запрещены — запрещены пустые.
25. Сломанный иврит / RTL: разрывы слов, наезды, нет глифов, английские подписи и капс-«доверие» («SECURED BY…»), шеврон символом, скролл не с того края, составное число вразнобой → `critic-design` §5.
26. Люди — инициалы на однотонной заливке / силуэты → живые фото (пак `research-assets/people/`).
27. Серые кнопки второго уровня + тёплый фон как привычка; три кнопки трёх стилей в шапке → одна первичная, второй уровень одним стилем; фон — из паспорта, с причиной.

29. Одинаковые серые пилюли на все действия экрана (вторичное, «все», «добавить» одной формой); статус, который ищут, — серым текстом → лестница действий: заливка · пилюля с оттенком бренда · текстовая ссылка у заголовка раздела; статус — чип слово + цвет семьи (✓ Влад 07.11).

**Недобор — «вайрфрейм вместо премиума»**
28. «Премиум» прочитан как «убери всё»: герой / основной < 1,8, акцентов 0, отступы равные везде, обводки на всём, серые боксы-плейсхолдеры, ни одной вещи под продукт → чек-лист **наличия**: герой / основной ≥ 2,5 (мобайл; десктоп и журнальный — 4) · 1 акцент там, где действие · волосяные линии вместо плашек · ритм 1:2:3 · один материал · число и единица на одной базовой линии · иконки одного набора. Страница с вычищенными теллами и ничем взамен — тоже телл (инвентарь: `void_pct`, `blank_gap`, `lead_ratio`).

**Проверка на грязь и на скуку** — одной фразой: убрать приём — стало хуже? нет → лишний. Убрать всё — остался вайрфрейм? да → недобор. Цель — «не всегда просто, всегда чисто»: богато можно, если одна иерархия и одна громкая зона.

## 4. Как пользоваться
- **Порядок чтения:** ресерчер — §0 (у каждого рефа строка «Линза» и баланс; «скучно» не предлагать опорой, «перегружено» — только за отдельный приём); дизайнер — §0 + §2 до концептов (у концепта: какая Л закрыта чем, какой телл обойдён, что нарисовано под продукт), перед сдачей самопроверка — баланс «норм»; критик — §0 + §2 в проходе 3 (`critic-design` §3). Примеры с цитатами — `taste-log.md` (§1 «Нравится», §3а / §3 галерея) точечно по номерам.
- **Галерея — глаз, не каталог:** рефы под проект ищутся заново (`research-visual-refs`); `good/` / `bad/` — чтобы оценить найденное линзой. Из примера берётся отмеченный ход, не сфера и не значения; ход из `good/` в проект — только если решает задачу экрана, с пометкой «из галереи».
- **Реф расходится с галереей → находка, не отсев:** хорош по линзе, но спорит с пунктом §0 / §2 → Владу с пометкой «расходится с п. N; чем хорош: …».
- **Вкус ≠ правило проекта:** пункт спорит с образом заказчика → развилка Владу (`shared-lead` §5 п. 9); его ответ → STATE, для проекта важнее этого файла.
- **Новая правка Влада:** правило — сюда одной строкой с проверкой (в таблицу §0 или список §2), пример с цитатой и датой — в `taste-log.md`.
