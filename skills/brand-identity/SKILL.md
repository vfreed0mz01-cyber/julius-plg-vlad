# Бренд (айдентика)

## 1. Когда и кто
Только при брифе «бренда нет» / «делаем бренд» / «редизайн логотипа»; есть бренд заказчика → этап пропускается, токены берут его hex и шрифт из STATE. Агент `brand-designer`; место — после рамки и ниши, до `research-visual-style` (`shared-lead` §3 п. 4а). Объём цифровой: знак, цвет, шрифт, элемент + паттерн, иконка приложения, сплэш, мини-гайд; мерч / печать / вывески — только по отдельному слову Влада.

## 2. Вход
`01-spec/brief.md` и рамка (для кого, обещание, тон), `02-research/niche.md` (конкуренты), STATE (язык, рынок, ограничения, «нельзя»), `shared-taste` §0.

## 3. Шаги

### 3.1 Позиционирование и культурный контекст
Фраза «что это и для кого» + характер тремя словами — из рамки, не выдумывать. Культурная деталь (`good-42`: скруглённые углы — в Китае острые читаются как неустойчивость): для иврита / RTL проверить знак рядом с ивритским словом и латиницей, направление движения в знаке («вперёд» в RTL — влево), цифры, местные символы. Найденное — строкой в STATE.

### 3.2 Аудит конкурентов (5–8 из ниши)
По каждому: знак (слово / буква / символ), ведущий цвет (`research-visual-anatomy/palette.py --pick`), шрифт, иконка приложения. Итог — таблица точками + **карта цветов**: что занято, где свободное поле. Проверка: ведущий цвет направления не совпадает (ΔE заметна на глаз) с главным конкурентом.

### 3.3 Направления → остановка **Б1**
2–3 направления, у каждого: образ из объекта продукта (Л6: цвет и форма от объекта), мудборд 6–9 картинок, характер, цветовое поле из свободной зоны, черновой знак-идея. Владу — картинкой (страница `Brand`), с рекомендацией.

### 3.4 Знак ч/б → остановка **Б2**
- Только форма, без цвета: цвет, показанный до утверждения формы, — нарушение порядка.
- Состав: wordmark (из шрифта) + сокращённая форма (буква, монограмма, элемент) для иконки и аватара.
- Строится в Figma из шрифта и фигур (`figma-use`) на сетке построения — сетка показывается Владу. Растр из генератора финалом не бывает; наброски — промпт пишет агент, генерирует Влад.
- Проверки: узнаётся в 16 / 32 / 48 px; на светлом и тёмном; одним цветом; рядом с ивритским словом. Знак-абстракция (свуш, волна, буква в круге) без связи с объектом продукта, градиент или 3D в знаке → находка.

### 3.5 Цвет, шрифт, элемент → остановка **Б3**
- **Цвет:** 1 ведущий + 1–2 акцента + нейтрали с подмесом; у каждого роль и причина одной строкой (`good-41`); AA на основных парах. 2 концепции карточками «01 / 02» — по паре кружков. Палитра без ролей или цвет как у главного конкурента → находка.
- **Шрифт:** пара латиница / иврит; иврит — без засечек; Julius — личный шрифт Влада, не дефолт.
- **Фирменный элемент — выводится из знака** (`good-42`: полоса со скруглением из буквы S; `good-41`: капсула-пятно); из него паттерн и мотив страниц (Л8: одна форма на систему). Элемент, придуманный отдельно от знака, → находка (декор, не система).
- **Фото:** ч/б или приглушённые, цвет только у бренда; либо фото, уже похожее на бренд.

### 3.6 Примерка
Иконка приложения 1024 и 48 px (сокращённая форма; слово целиком в 48 px не читается → находка), сплэш, первый экран, шапка сайта / OG, аватар; светлый и тёмный фон. Линза `shared-taste` §0: баланс «норм». Иконки — свой набор, эмодзи / стоковые / Lucide = находка.

### 3.7 Мини-гайд
`03-design/brand.md` + страница `Brand`: знак (версии, охранное поле, минимальный размер, «нельзя»), цвета с ролями и hex, шрифты, элемент и паттерн, примерка. Решения Б1–Б3 → STATE. Токенист берёт `brand.md` как источник «бренд» (`design-tokens` §3).

## 4. Формат выхода
```
# Бренд: <продукт>
## Позиционирование · характер · культурная деталь
## Конкуренты (таблица точками + карта цветов, свободное поле)
## Направления 1–3 (образ, мудборд, поле) → Б1 ✓ <выбор Влада>
## Знак (ч/б, сетка, проверки 16/32/48) → Б2 ✓
## Цвет (роль + причина + hex, AA) · Шрифт · Элемент и паттерн → Б3 ✓
## Примерка (иконка, сплэш, экран, сайт) · Линза
## Для токенов: hex, шрифты, элемент
```
