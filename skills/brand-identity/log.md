# Бренд (айдентика)

> v0 (2026-10-06, ✓ Влад: «да, всё делай как рекомендуешь»). Скелет взят из кейсов Purrweb — Shaoke (знак в ч/б → культурная деталь → цвет по конкурентам → 2 концепции → паттерн из знака → примерка → гайд) и EvTrip (палитра с причиной у каждого цвета, форма знака как мотив всей системы); разбор — `shared-taste` `good-41`, `good-42`.

## 1. Когда и кто
- **Только если** в брифе «бренда нет», «делаем бренд» или «редизайн логотипа» (`/design-start` спрашивает). Есть бренд заказчика → этап пропускается, токены берут его hex и шрифт из STATE.
- Агент `brand-designer`. Место в цепочке (`shared-lead` §3 п. 4а): **после рамки и ниши** (нужны позиционирование и конкуренты), **до стиля** визуального ресерча (`research-visual-style` получает бренд как вход) и задолго до токенов.
- **Объём — цифровой** (✓ Влад 06.10): знак, цвет, шрифт, фирменный элемент + паттерн, иконка приложения, сплэш, мини-гайд. Мерч, печать, вывески, упаковка — только по отдельному слову Влада.

## 2. Вход
`01-spec/brief.md` и рамка продукта (для кого, обещание, тон), `02-research/niche.md` (конкуренты), STATE (язык, рынок, ограничения заказчика, «нельзя»), `shared-taste` §0 + §0а (вкус Влада и линза).

## 3. Шаги

### 3.1 Позиционирование и культурный контекст
- Одна фраза «что это и для кого» + характер тремя словами («строго · быстро · надёжно»). Из рамки, не выдумывать.
- **Культурная деталь** — как скруглённые углы у Shaoke (в Китае острые углы — неустойчивость). Для иврита / RTL проверить: знак рядом с ивритским словом и латиницей; направление движения в знаке (стрелка «вперёд» в RTL смотрит влево); цифры; символы с местным смыслом. Найденное — строкой в STATE.

### 3.2 Аудит конкурентов (5–8 из ниши)
По каждому: знак (тип: слово / буква / символ), ведущий цвет (hex через `research-visual-anatomy/palette.py --pick`), шрифт, иконка приложения. Итог — **карта цветов**: что занято, где **свободное поле** («сине-зелёную гамму в нише ещё никто не взял»). Таблица точками (есть / нет), как у EvTrip, а не абзацем.

### 3.3 Направления → остановка **Б1**
2–3 направления. У каждого: **образ из объекта продукта** (`shared-taste` §0 п. 2 — цвет и форма идут от объекта), мудборд 6–9 картинок, характер, цветовое поле из свободной зоны карты, черновой знак-идея. Владу — картинкой (доска `Brand` в Figma), с рекомендацией.

### 3.4 Знак в ч/б → остановка **Б2**
- Сначала **только форма, без цвета** — иначе обсуждают цвет вместо формы.
- Состав: wordmark (из шрифта) + простой знак / сокращённая форма (буква, монограмма, элемент) для иконки и аватара.
- Строится в Figma из шрифта и простых фигур (`figma-use`), на сетке построения — сетка показывается Владу. ИИ-растр знаком не бывает. Нужны наброски форм — агент пишет промпт, генерирует Влад (как эскиз П9).
- Проверки: узнаётся в **16 / 32 / 48 px**; работает на светлом и тёмном; одним цветом; рядом с ивритским словом.

### 3.5 Цвет, шрифт, фирменный элемент → остановка **Б3**
- **Цвет:** 1 ведущий + 1–2 акцента + нейтрали с подмесом. У каждого — **роль и причина** («жёлтый — энергия, чёрный — контраст», EvTrip); контраст AA на основных парах. 2 концепции цвета карточками «01 / 02» — по паре кружков, без лишнего.
- **Шрифт:** пара латиница / иврит; иврит — только без засечек; Julius — личный шрифт Влада, не дефолт проекта.
- **Фирменный элемент выводится из знака** — полоса со скруглением с одной стороны из буквы S (Shaoke), капсула-пятно (EvTrip). Из него — паттерн и мотив страниц (`shared-taste` §0 п. 4, 16: одна форма на систему). Элемент несёт смысл продукта (у Shaoke — связь и движение, обводит грузовик, самолёт, корабль).
- **Фото:** ч/б или приглушённые, цвет только у бренда; либо фото, которое уже похоже на бренд (контейнеры = паттерн, жёлтый скутер = жёлтый бренд).

### 3.6 Примерка
Иконка приложения 1024 и 48 px (**сокращённая форма, не слово целиком**), сплэш, первый экран продукта, шапка сайта / OG-картинка, аватар соцсети; светлый и тёмный фон. Прогон линзой (`shared-taste` §0а): баланс «норм».

### 3.7 Мини-гайд
`03-design/brand.md` + страница `Brand` в Figma: знак (версии, охранное поле, минимальный размер, «нельзя»), цвета с ролями и hex, шрифты, элемент и паттерн, примеры примерки. Решения Влада Б1–Б3 → STATE. **Токенист берёт `brand.md` как источник значений «бренд»** (`design-tokens` §3).

## 4. Формат выхода
```
# Бренд: <продукт>
## Позиционирование · характер · культурная деталь
## Конкуренты (таблица точками + карта цветов, свободное поле)
## Направления 1–3 (образ, мудборд, поле) → Б1 ✓ <выбор Влада>
## Знак (ч/б, сетка, проверки 16/32/48) → Б2 ✓
## Цвет (роль + причина + hex, AA) · Шрифт · Элемент и паттерн → Б3 ✓
## Примерка (иконка, сплэш, экран, сайт) · Линза
## Для токенов: hex, шрифты, элемент
```

## 5. Типичные провалы
- Знак-абстракция «свуш / волна / буква в круге» без связи с продуктом; градиент или 3D в знаке.
- Иконка приложения = слово целиком (в 48 px не читается).
- Цвет как у главного конкурента; палитра без ролей («просто красиво»).
- Цвет показан Владу раньше, чем согласована ч/б форма.
- Фирменный элемент придуман отдельно от знака — системы нет, есть декор.
- Эмодзи и стоковые иконки вместо своего набора; Lucide как дефолт запрещён.
- Знак-растр из генератора выдан за финал.
