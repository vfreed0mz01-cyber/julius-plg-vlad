# Токены

## 1. Когда и кто
- После остановки ② ресерча и выбора направления Владом (`shared-lead` §5 п. 6); значения — из выбранного кадра и `measures.md`.
- Агент `tokenist`. Только значения и обоснование; в Figma не пишет. Токенист ≠ сборщик DS (разные запуски).
- Пилотом — токены одного экрана; расширять по пачкам. Токен без поля `use` не заводится.

## 2. Вход
STATE (решения Влада: бренд, фон, шрифты, радиусы, иконки, семьи статусов), параметры вайрфреймов, `02-research/visual/color-type.md` («Что передаём Дизайну»), `refs.md`, `assets.md`, `measures.md`, `03-design/brand.md` (если был бренд), бриф (регистр, 50+, RTL), кадры экрана-пилота и лист.

## 3. Источник у каждого значения
Токен = `value` + `source` + `use`. Допустимые источники: **замер** рефа (ID из `refs.md` / `measures.md`), **бренд** (hex из STATE или `brand.md`), **решение Влада** (строка STATE), **вывод** из другого токена по правилу (шаг OKLCH-шкалы, пол AA, норма платформы — с названием правила), **параметр вайрфреймов**. Запрещены: «из памяти», генераторы палитр, библиотеки (Tailwind / Material / Bootstrap / Radix / Open Color), 100 %-насыщенные hex, «голый» серый без подмеса оттенка (подмес — от бренда или замера фона рефа). Проверка: `tokens_check.py` → STOCK = 0, «нет источника» = 0.

## 4. Слои
1. **Примитивы цвета** — OKLCH-шкалы вокруг якорей (бренд, тёплый тон, нейтраль с подмесом): шаг по L ровный; C на крайних ступенях ≤ 0.5 C середины. Утилиты: `tokens_check.py --oklch HEX`, `--hex L C H`.
2. **Семантика цвета** — роли, не оттенки (`blue-500` → находка): `surface/page|raised|sunken`, `ink/1–3`, `line/hair|strong`, `accent/fill|on|wash`, статусы по семьям STATE (`status/<семья>` с `ink` и `wash`), `meter/fill` ≠ `meter/track` (контраст ≥ 3:1), `focus`. Акцент не в хроме: токены `accent/*` в `use` только у действия и выбранного. Цвет — не единственный носитель (форма / слово рядом). «Выбрано» — разница светлоты ≥ 3:1 без галочки (`critic-design` §5).
3. **Шрифт** — роли (`display`, `title`, `heading`, `body`, `body-strong`, `label`, `caption`, `amount-l|m`) → семейство по письменности (иврит / латиница и ₪ / цифры), размер, высота строки, вес, трекинг. Размеры — по шкале платформы (iOS body 17, вторичный 15, подпись ≥ 12; не увеличивать «для 50+» — 50+ = понятность, P15). Глифы, которых нет в основном шрифте, → роль партнёра явно, с коэффициентом выравнивания x-height (замер).
4. **Отступы** — из параметров вайрфреймов; новое значение — только с причиной в `source`.
5. **Радиусы** — по решению Влада в STATE; радиус = тип элемента (значений ≤ порога инвентаря).
6. **Иконки** — набор (по умолчанию сплошные глифы в духе SF; контурные — по паспорту, тогда штрих = вес шрифта, замер из `assets.md`), размеры по контексту (строка / таббар / кнопка).
7. **Прочее** — тени (обычно нет), прозрачности как именованные wash, толщина линий.
8. **Материалы** — только при паспорте «со слоями» (STATE: «глубина со слоями · реф · Влад»). `material/<имя>` = `fills` (снизу вверх: база, свет, затемнение) + `stroke` + `effects` + `light` + `source` («слои поверхности» из разбора рефа) + `use`. На продукт 2–3 материала, один источник света; цвета слоёв — из примитивов. Материал, записанный одним значением («стекло = белый 10 %»), → находка: всегда рецепт из слоёв (`design-components/materials/recipes.md`). Текст на материале — пара `check/*` по худшей точке. Слои `tokens_check.py` не проверяет — критик рядом с рефом.

## 5. Пары контраста
В `pairs` — каждая реальная пара экрана-пилота: `text` 4.5 · `large` (≥ 24 или ≥ 19 bold) 3 · `ui` (значки, границы, полосы) 3. AA — пол, AAA не требуем. Бледный текст из рефа берём стилем, контраст чиним значением. Акцент в роли цвета ключевых чисел — только если пара с фоном ≥ 4.5.

## 6. Выход
- `03-design/tokens.json` — машинный (формат — шапка `tokens_check.py`).
- `03-design/tokens.md` — таблицы по слоям (токен · значение · источник · где), шкалы образцами, «развилки» (2–3 варианта + рекомендация) — только равноценные вкусовые; вытекающее из решений Влада — [В].
- `03-design/tokens-preview.png` — шкалы, роли на поверхностях, шрифтовая шкала на иврите с суммами в ₪ (Chrome headless). Владу — картинкой.
- `python3 tokens_check.py 03-design/tokens.json` → «LINT: чисто» — условие сдачи.

## 7. Границы
Не меняет решения Влада и вайрфреймы (конфликт → в развилки); не собирает Figma; не добавляет токен «на будущее»; 50+ ≠ огромный шрифт и ЧБ.
