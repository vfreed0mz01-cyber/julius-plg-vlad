# Инвентарь экрана

Грязь — не вкус, а разнобой, который считается. Скрипт, не глаз.

## 1. Когда и кто
- **Дизайнер экрана** — после сборки кадра, до самоитераций (`design-screen` §2 шаг 7–8).
- **Критик дизайна** — проход 1, до слепого просмотра (`critic-design` §1).
- Лид прикладывает таблицу к показу Владу вместе со скриншотом.

## 2. Как запустить
1. `inventory.js` → в `use_figma`, `FRAME_ID` = id кадра → JSON → `04-critic/inventory/<экран>-<вариант>.json` (по файлу на вариант).
2. `python inventory_check.py <json> --profile <mobile-card|desktop-table|desktop-dense> [--premium] [--layered] [--thresholds <путь>] [--md <экран>.md]`
   - профиль — из карты композиции (`screen-composition`); нет карты → `mobile-card` для 390, `desktop-table` для ≥ 1024;
   - `--premium` — паспорт «строго / премиум / как Apple»;
   - `--layered` — только при записи в STATE «глубина со слоями · реф · Влад»;
   - пороги: плагина — `skills/screen-inventory/thresholds.json`; проекта — `03-design/thresholds.json` (скрипт берёт проектный, если файл есть в текущем проекте, или путь из `--thresholds`).
3. Таблицу — в отчёт целиком, без пересказа.

## 3. Что считается и что значит ✗
| показатель | о чём говорит | лечение |
|---|---|---|
| веса > 3, кегли > 5 | типографика без системы | 2 веса в тексте + третий у заголовка / сумм (по рефам); кегли — шкала `tokens.md` |
| _(0.7.6)_ внутри экземпляров DS | — | стиль внутри экземпляра (таббар, статус-бар, кнопка) не считается; строка «Внутри DS: N» — сборщику DS, не дизайнеру |
| герой / основной < порога | всё одного размера, героя нет | герой ≥ 1,8× основного текста (премиум мобайл 2,5, десктоп 4) |
| серые > 3 | серый «на глаз» | ступени `ink/1–3` |
| радиусы > N | радиус не по типу элемента | радиус = тип элемента (`good-24`) |
| акцентные оттенки > N | цвет без роли; факт как предупреждение | один акцент = действие; статусы — семьи STATE |
| тень + обводка на узле | элемент «одет» дважды | тон или волосяная обводка |
| одинаковая пара подряд > 2 | «жирный + серый» лентой | третий блок меняет форму или в строки |
| блоки-клоны > 2 | карточки-клоны вместо списка | строки с воздухом (`good-11`) |
| крупных образов > 1 | два героя | один; второй иконкой / строкой |
| первичных кнопок > 1 | нет главного действия | одна залитая, остальные одного тихого стиля |
| ряды контролов разной высоты | кнопка 48 рядом с чипом 36 | одна высота на ряд |
| заливок без переменной > 10 % | мимо токенов | привязать / дыра токенисту |
| `void_pct` > порога | недобор: вычищено, взамен ничего | герой, типографский акцент, собранная группа (`shared-taste` §2 телл 28) |
| `blank_gap` > порога, px | ничейная пустота между блоками | ритм 1:2:3 или опора внизу (`good-26e`) |
| `lead_ratio` < 1.3 | числа одного размера, KPI не читается | ведущая ≥ 1.3× (премиум ≥ 1.6×) |
| иконок в кружках > порога | дефолт дашбордов (B2B: 0) | иконка без подложки (сплошная или контурная — по паспорту), или все в одинаковых кругах по паспорту |
| высота строк списка вне 36–53 | строки-карточки или давка | desktop-table 36–53, dense 32–48 |

Показатели с порогом `—` для профиля не считаются (в таблице клоны и повторы — норма).

## 4. Режим Б
- Превышение — не возврат. Дизайнер в «## Дизайн» по каждому ✗ — одна строка: **починил** (что) или **оправдано** (причина из задачи пользователя, STATE или образа заказчика). «Так в рефе», «красивее», «для разнообразия», оправдание без причины → ✗ остаётся, находка критика.
- Лид ведёт в STATE «Снятия порогов»: показатель · экран · причина · дата. Один показатель снят > 3 раз с одной причиной → не исключение, а стиль проекта: порог переписать в `03-design/thresholds.json` с записью решения Влада, не снимать четвёртый раз.
- Критик проверяет строки «починил / оправдано» и прогоняет скрипт заново (расхождение чисел — находка), не оправдывает за дизайнера.
- Влад видит таблицу и экран вместе: соглашается с оправданием или правит порог проекта.

## 5. Варианты
Таблица на каждый вариант + строка «чем отличаются по инвентарю» («A: 1 акцент, тени 0; B: 2 акцента, тени 4»). Одинаковые таблицы = не разные варианты (`design-screen` §4).

## 6. Границы
Скрипт не знает смысла (факт ≠ предупреждение, герой ≠ декор — это `critic-design` §3). Не меняет Figma, не лечит. Пороги стартовые: калибруются по экранам, которые Влад принял.
