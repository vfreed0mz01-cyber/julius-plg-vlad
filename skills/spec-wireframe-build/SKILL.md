# Сборка вайрфреймов

> v1 (2026-10-23) — коротко; история — `log.md`. Решения и исполнение разделены: проектировщик решает, сборщик точно исполняет.

## 1. Вход и границы
Лист решений `01-spec/screens/<№>-<название>.md` — только **прошедший оппонента** (`critic-logic`) и выжимку «Спорное» у Влада · STATE («Параметры вайрфреймов проекта», Figma-файл) · файл с китом (`shared-wireframe-kit`; кита нет → сначала запустить) · `research/professional-wireframes.md`. Figma — `shared-runtime` §3; правила кадра — `shared-wireframe-kit` §3.
- **Не менять решения** листа. Невозможно исполнить (не влезает, противоречие) → собрать максимально близко, находку — в аннотацию и в конец листа.
- **Не добавлять** элементов, которых нет в листе. **Проверка:** каждый узел кадра находит строку в листе.
- **Не стилизовать**: только серая шкала кита; кликабельное — `color/action`.
- После сборки — `critic-wireframe` отдельным агентом; сборщик себя не проверяет.

## 2. Как собирать
1. `figma:figma-use`. Страница «Wireframes — Mobile» (или «Wireframes — Desktop»); нет страницы — спросить Влада, потом создать (`shared-wireframe-kit` §3 п. 2).
2. **Фрейм экрана**: размер из параметров (мобайл 390 × 844; длиннее — высота по содержимому, линия первого экрана в аннотации) · имя `<NN> <Screen name in English> — <Role>` · вертикальный auto-layout · колоночная сетка по §3 п. 5 кита · сверху статус-бар, внизу таббар и home indicator (для экранов со вкладкой) — инстансы настоящих компонентов iPhone (`shared-wireframe-kit` §4), не заглушки `WF/*`.
3. **Зоны — вложенные auto-layout фреймы** в порядке листа, имя зоны = имя из листа; отступы переменными (§3 п. 4 кита).
4. **Элементы — инстансы кита**, текст через свойства компонента. Нет компонента → добавить в кит скриптом (`shared-wireframe-kit` §5), не рисовать разово; исключение — уникальный для экрана блок.
5. **Контент — реальный, на иврите**, из листа; длинные значения — по правилу листа (перенос или «…»); RTL — §3 п. 3 кита.
6. **Заливка `color/surface` и радиус `radius/container` — только где лист сказал**; по умолчанию группы отделены воздухом. `clipsContent = false`.
7. **Аннотации** (справа от фрейма, вне экрана, по-русски): на элементах — метки `WF/Annotation` с номерами; справа колонка заметок `N — решение · почему · реф (ссылка)`; линия конца первого экрана; блок **«Условности вайрфрейма»** — что условно и ждёт Дизайна (разделители «·», подача формулировок, размеры, формы).
8. **Проверка скриншотом** (`node.screenshot()`, §3 п. 6 кита): текст не обрезан, ничего не перекрывается · ранг 1 в первом экране · главное действие одно, ≥ `size/touch`, в зоне пальца · нет сирот (у каждого узла — зона) · заливки только по листу · все отступы — переменные · `layoutGrids.length ≥ 1` · имена английские, контент иврит.

## 3. Формат выхода
- Фрейм экрана + аннотации в Figma.
- В конце листа решений — раздел `## Сборка`: ссылка на фрейм (node-id), что не удалось исполнить и почему, какие компоненты добавлены в кит.
