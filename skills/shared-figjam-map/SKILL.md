# Карта проекта в FigJam

## 1. Перед началом
- Загрузить `figma:figma-use` и `figma:figma-use-figjam` до `use_figma`; FigJam-грабли (`clone` → `appendChild`, конец коннектора в px) — `shared-runtime` §3.
- Доска — из STATE «Карта проекта». Нет → спросить Влада, есть ли уже; только потом `figma:figma-create-new-file` «<Проект> — карта проекта», ссылку в STATE.
- Сначала `get_figjam`; чужие элементы (не из наших секций) не трогать.

## 2. Язык
Всё по-русски; иврит — только в скобках для сверки со спекой. Проверка: в тексте стикеров нет ивритских / английских строк вне скобок.

## 3. Раскладка доски
- **Заголовок** над картой: «<Проект> — карта экранов (<этап>)» + легенда. Новый статус / цвет → сначала в легенду, потом на стикеры.
- **Секция = роль × платформа.** Первым главный пользователь, потом второстепенные роли, отдельно «Системные экраны — открываются с любого экрана». Экран, общий для ролей, — одна карточка в общей секции, различия строкой «Права: …».
- **Внутри секции — зоны по навигации:** вход (сплэш, вход, OTP) — левая колонка; главная; разделы таббара / меню. Зоны с глубиной ≤ 2 — друг под другом (зона = строка), колонками — только уровни вглубь. Проверка: ширина секции ≤ 4000 px.
- **Строка под заголовком секции:** структура навигации (таббар / меню, шапка).
- **Пуши** — стикер-таблица «Пуши» в углу секции: событие → экран → «назад».
- **Справка** (жизненные циклы и т. п.) — сбоку, x ≥ карта + 9000; под картой — ничего.

## 4. Карточка экрана
Широкий стикер (`isWideWidth = true`), шрифт 18, автор скрыт. Первая строка Inter Bold, остальное Inter Medium: грузить оба начертания, шрифт ставить по диапазонам после записи текста (`loadFontAsync(text.fontName)` падает на `figma.mixed`).

```
№<N> · <НАЗВАНИЕ ЗАГЛАВНЫМИ> · <Пр1–Пр5> · <метки>
Что: <зачем экран пользователю>
Инфо: <какую информацию даёт, через « · »>
Вход: <как попасть; все входы, если экран на нескольких уровнях>
Ведёт: <куда>            (можно опустить, если показано стрелками)
Назад: <куда>            (если не очевидно: пуш, глобальный экран)
Подформы: <sheet, панель — не отдельными стикерами>
Состояния: <загрузка · пусто · ошибка · доменные>
```

Метки первой строки: `+ добавлен` (нет в спеке) · `⚠ спека ссылается, экрана нет` · `✓ решено: …` · форма, если не экран: `sheet` / `диалог` / `панель`. Экран с входами с разной глубины — одна карточка на «главном» уровне, остальные входы — в строке «Вход».

**Цвет = приоритет** (hex/255):

| Приоритет | Цвет | Hex |
|---|---|---|
| P1 якорь | оранжевый | `#FFD3A8` |
| P2 вход | фиолетовый | `#D3BDFF` |
| P3 основные | зелёный | `#B3EFBD` |
| P4 второстепенные роли | бирюзовый | `#B3F4EF` |
| P5 системные | серый | `#E6E6E6` |
| внешний узел | белый | `#FFFFFF` |

Проверка: цвет стикера совпадает с приоритетом экрана в `navigation.md`.

## 5. Стрелки
- Коннектор `ELBOWED`, стрелка на конце, серый `#757575` = путь «откуда → куда»; путь предложен командой, в спеке нет → красный `#FF7556`, `dashPattern [10, 10]`.
- Рисовать только пути P1–P2-экранов и переходы «главная → раздел» из `navigation.md`; «назад», модальные потоки и глобальные экраны — строкой «Вход» / «Назад», не стрелкой. Проверка: нет стрелки длиннее одной секции.
- Магниты явно: вглубь — `RIGHT → LEFT`, внутри зоны — `BOTTOM → TOP`; конец — `position` в px от узла (не доли 0–1). Стрелка режет карточку → убрать, путь в строку «Вход».
- Циклы в справке — `STRAIGHT` с разными точками крепления; встречные переходы — две параллельные линии (ELBOWED с общим концом сливается).
- Стрелки — дочерние элементы секции.

## 6. Раскладка — два прохода
1. Создать стикеры секции, текст и цвет.
2. Прочитать реальную высоту каждого; высота строки = максимум по строке; сетка: колонка 416 + 110, между строками 90.
3. Секция по содержимому + 40 по краям.

≤ 25 стикеров на вызов `use_figma`; возвращать id созданных узлов. Карточка выросла от правки → сдвинуть соседей ниже в колонке и подогнать секцию. Проверка после каждого прохода и роста: скриншот секции (`get_screenshot`, `enableBase64Response: true`), текст не обрезан, рамки стикеров (x, y, w, h) не пересекаются.

## 7. Обновление после ответов Влада
- Править на месте (текст и цвет существующих карточек); перерисовка карты = потеря правок Влада → находка.
- Решённое → `✓ решено: …`, снять `⚠` и `?`. Новый экран — стикер рядом с родственными + стрелки. Слитый экран — удалить стикер, содержимое в карточку родителя.
- После обновления — проверка §6.
