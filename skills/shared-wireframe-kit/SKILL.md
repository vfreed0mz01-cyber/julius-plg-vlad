# Вайрфрейм-кит

> v1 (2026-10-23) — коротко; история — `log.md`. Все экраны единообразны (auto-layout, компоненты, переменные); дизайн ложится поверх сменой стилей и значений; имена переменных общие, значения — из STATE.

## 1. Как запустить
1. `figma:figma-use` (обязательно перед `use_figma`); Figma — `shared-runtime` §3.
2. Design-файл проекта — из STATE. Нет → спросить Влада, нет ли уже; затем `figma:figma-create-new-file`, имя «<Project> — wireframes», ссылку в STATE.
3. Скрипты из этой папки по порядку через `use_figma` (содержимое файла — как `code`):
   - `kit-1-foundations.js` — страница кита, коллекция переменных `WF`, текстовые стили `WF/*`. **Перед запуском поправить `PARAMS`** под параметры проекта: поля, отступы, зона нажатия, базовый текст, шрифт.
   - `kit-2-base.js` — иконка-заглушка, бейдж, кнопка-иконка, кнопка (Primary / Secondary / Text), чип, фото-заглушка, аватар, метка аннотации.
   - `kit-3-composite.js` — шевроны (RTL), статус-бар и home indicator (заглушки-fallback, см. §4), шапка корня, шапка «назад», строка списка, заголовок секции, число с подписью, таббар (4 вкладки, RTL).
   - **`kit-1…3` — общий кит; `kit-4+` — проектные скрипты Mayors (home, payment flow, login, dubai, deal), в новом проекте не запускать.**
4. Скриншот страницы кита (§3 п. 6): ничего не обрезано, тексты справа; у наборов вариантов `primaryAxisSizingMode` / `counterAxisSizingMode = AUTO`, иначе обрезаны.

## 2. Состав
- **Переменные `WF`**: `color/*` — серая шкала `bg` · `surface` · `placeholder` · `line` · `text-secondary` · `text` · `action` (самый тёмный, для кликабельного) · `on-action`; `layout/margin-screen` · `layout/gutter` · `gap/in-group` · `gap/between-groups` · `size/touch` · `radius/control` · `radius/container` · `space/4…48`.
- **Текстовые стили `WF/*`**: заголовок экрана · заголовок секции · число крупное · основной · основной акцент · кнопка · подпись · метка; размеры — от базового текста проекта.
- Кликабельное — `color/action`, не цветом. Иконки — заглушки (кружок), смысл — подписью или в аннотации. Фото — заглушка с крестом и подписью на иврите. Единственный цвет в файле — оранжевая метка аннотации, только вне экранов. Скругления нейтральные (4 / 8), финальные задаёт Дизайн.

## 3. Правила кадра (сборщик и критик ссылаются сюда)
1. **Имена — английские**: страницы («Wireframes — Mobile»), фреймы (`<NN> <Screen name> — <Role>`), зоны, слои, компоненты, свойства, варианты, стили, переменные. Контент — иврит, аннотации — русский. **Проверка:** обход узлов кадра — ни одного имени с кириллицей.
2. **Новый файл или страница — только после вопроса Владу**, нет ли уже.
3. **RTL**: в горизонтальных auto-layout логический порядок перевёрнут — главное справа; вертикальные контейнеры `counterAxisAlignItems = MAX`; текст `RIGHT`; шеврон «назад» смотрит вправо, «вперёд» — влево; числа и даты в LTR-изоляции. **Проверка:** первый элемент чтения в каждой строке — у правого края.
4. **Отступы и цвета — только переменными** (`setBoundVariable`): поля экрана `layout/margin-screen`, внутри группы `gap/in-group`, между группами `gap/between-groups`. **Проверка:** обход узлов — у каждого `padding* / itemSpacing / fills` есть `boundVariables`.
5. **Колоночная сетка** (`layoutGrids`) из параметров проекта на каждом кадре, включая варианты; поля и промежуток привязаны `setBoundVariableForLayoutGrid`; проще скопировать с утверждённого кадра. **Проверка:** `frame.layoutGrids.length ≥ 1` кодом — скриншот сетку не показывает.
6. **Скриншот — через `node.screenshot()` в `use_figma`**, не серверный `get_screenshot` (переворачивает иврит); общий план и зоны крупно (scale 1.5–2).
7. `clipsContent = false` у контейнеров; ничего не обрезано.
8. Контейнеры группы (заливка `color/surface`, радиус `radius/container`) — только где лист решений сказал; по умолчанию группы отделены воздухом.
9. Не трогать чужое — `shared-runtime` §3.

## 4. Системные элементы iPhone — настоящие компоненты
Статус-бар, home indicator и клавиатуры не рисуем — инстансы компонентов iPhone Влада (Mayors: страница «Page 1» файла вайрфреймов). Карта `IOS` (id + key) и функции `iosComp(ref)` / `fitKeyboard(inst)` — в начале `kit-3-composite.js` (копии в kit-6 / kit-8 / kit-10). Порядок поиска: id с проверкой key → `importComponentByKeyAsync` (если библиотека опубликована) → серая заглушка `WF/*`.
- **Статус-бар** — `Status bar - iPhone`, `Property 1=dark` `171:4616` (тёмные значки, светлый фон); `white` `171:4614` — на тёмном фоне / фото. 390 × 47, без заливки.
- **Home indicator** — `home-indicator` `171:4635`, 358 × 34, без заливки → в кадре ширина 390 (FILL в auto-layout, иначе `resize(390, 34)`, x = 0).
- **Клавиатуры** — `Keyboard/Default` (отдельные компоненты; 402 шириной → `fitKeyboard`: 390 + дети FILL): Phone pad `171:6327` · Phone pad with suggestion `171:6333` (подсказка кода — тексты «Title» / «Text» во «Frame 2») · Email `171:6329` (подсказка — текст «Passwords») · Text `171:6331` · Numbers & symbols `171:6332` · тёмные `171:6330` / `171:6328`. Шрифт подсказок SF Pro Text недоступен — перед правкой текста сменить на `SF Pro` того же начертания. Клавиатуры — английская раскладка, без home indicator.
- Заглушки `WF/Status bar`, `WF/Home indicator`, `WF/Keyboard` — «УСТАРЕЛО», инстансов нет.

## 5. Расширение кита
Нужен новый повторяющийся компонент (таймлайн шагов, прогресс, карточка-контейнер, строка таблицы для десктопа) — скриптом `kit-N-*.js` в эту папку по тем же правилам: переменные, стили, RTL, текстовые свойства. **Проверка:** в экранах нет нарисованных вручную элементов, которые встречаются > 1 раза.
