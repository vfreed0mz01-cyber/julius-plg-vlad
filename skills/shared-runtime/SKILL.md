# Исполнение задания (общее для всех агентов)

## 1. Прочитать первым
1. Корневой `CLAUDE.md` проекта (кто такой Влад, языки, коннекторы); нет раздела «Кто такой Влад» → `${CLAUDE_PLUGIN_ROOT}/templates/CLAUDE.md`.
2. Свой файл агента и все скиллы из его списка: инструмент Skill (`design-team:<имя>`) или `${CLAUDE_PLUGIN_ROOT}/skills/<имя>/SKILL.md`. Скрипты скиллов — там же. `log.md` рядом со скиллом — история, грузить только по вопросу «почему так».
3. `projects/<name>/STATE.md` — решения Влада ✓ главнее всего; блок «Figma-узлы для агентов» — id файлов, страниц, зон. Решённое Владом заново не искать.
4. Дизайн-агенты и критики — `shared-taste/SKILL.md` целиком + картинки `bad/`; `taste-log.md` и `good/` — точечно по номерам из §0.
5. Входы из задания. Критик до слепых проходов **не** читает заметки исполнителя и аннотации над кадрами.

## 2. Сначала реши сам
Перед тем как выносить вопрос Владу: 2–3 варианта → выбор с обоснованием (задача пользователя + аудитория + 1–2 живых рефа с «почему так») → запись решения с меткой **[В]** и строкой «почему». Владу — только бизнес-факты, которые нельзя вывести, и равноценные развилки вкуса — с рекомендацией; раскладку — картинкой (эскиз А / Б), не словами. Список остановок — `shared-lead` §5.

**Перебор по разработке — стоп.** Если задание или реф тянут функцию, которой нет в спеке, или дорогую в разработке (своё 3D / AR / ML, реалтайм, видео, новые интеграции, платный API за каждое использование) — не рисовать её молча: строка лиду «похоже на L / XL: … · дешёвый путь: …» (`shared-lead` §4а). Красивый экран под функцию, которую не построят, — брак.

## 3. Figma и Mobbin
- **Figma**: `ToolSearch` → `select:mcp__Figma__get_figma_skill,mcp__Figma__use_figma,mcp__Figma__get_screenshot,mcp__Figma__get_metadata,mcp__Figma__upload_assets` (FigJam — + `get_figjam`). Перед первым `use_figma` — `skill://figma/figma-use/SKILL.md` (+ `figma-generate-design` для экранов, `figma-generate-library` для компонентов, `figma-use-figjam` для FigJam).
- **Mobbin**: `ToolSearch` с запросом `+mobbin search_screens` (имя сервера меняется — не вшивать uuid); `search_screens` (deep) для экранов, `search_flows` для потоков, `search_sections` — только секции веб-сайтов. Превью ~300 px; оригинал — `image_url`, скачивать сразу (ссылки живут 30 дней); цитировать `mobbin_url`.
- Сообщения «requires authentication» про плагины `figma` / `mobbin` — дубли; Влада авторизовать не просить, работать через коннекторы `mcp__Figma__*` / `mcp__Mobbin__*`.
- **Зона**: только своя зона страницы из задания; сначала прочитать страницу, зона занята → сдвинуться ниже и написать в отчёте.
- **Не трогать** без указания: кадры вайрфреймов и кит `WF/*`, компоненты DS (дыра → в отчёт), кадры других агентов и прошлых версий, фреймы Влада (STATE «Figma-узлы»), дерево Влада на карте процесса.
- **Только финал и развилки** на странице; итерации — PNG в репо; уменьшенных копий не делать. **Старые кадры** — в секцию `Archive` внизу страницы с префиксом `v0 — `, не удалять. **Временные кадры для развилки Владу** — имя с `TEMP`, удалить после решения.
- Аннотация над кадром — по-русски (что это, опора, отличия, мнение). Имена слоёв / компонентов / страниц — английские, экраны — иврит. Новый файл / страница — только если задание разрешает.
- Картинки — `upload_assets` (прямоугольник → POST байтов на выданный URL); `createImageAsync` не работает; сторона > 4096 — резать.
- Скриншоты: `get_screenshot` → скачать `curl -L`; 403 от прокси → `enableBase64Response: true`. Отдаёт 1× — для @2x: в `use_figma` `await node.exportAsync({format:"PNG", constraint:{type:"SCALE", value:2}})` (кропы — по узлам зон), копии кадра не нужны.
- FigJam: `node.clone()` кладёт копию в корень → `section.appendChild()`; конец коннектора — в пикселях от узла.

## 4. Окружение облачной сессии
- Хосты: mobbin.com, www.figma.com, mcp.figma.com, images.unsplash.com. Хост режется (403) → имя хоста в отчёт, лид передаст Владу.
- Фото-заглушки: `images.unsplash.com` по id, ≥ 3× слота, подпись «фото-заглушка», id — в заметках. Браузер — только просмотр, никаких действий аккаунтом.
- Python: Pillow есть; остальное — `pip install --target <scratchpad>`. Chromium — `/opt/pw-browsers`.

## 5. Параллельная работа
- Один агент — свои файлы. Общий файл (лист экрана, STATE, HANDOFF) правит только тот, кому сказано; остальные — в свой файл, лид сведёт.
- Две зоны одной страницы не пересекаются; чужие узлы не читать как свои.
- Обновление плагина не перезапускает этап: продолжать с текущих вариантов, новые правила — к следующему кадру.

## 6. Файлы и отчёт
- Результаты — по путям из задания; картинки — PNG рядом с заметками.
- **git — только лид.** STATE / HANDOFF не править, если не сказано.
- Отчёт лиду — **по-русски**, кратко: id узлов и пути; что сделано по пунктам задания; самопроверка (линт / инвентарь / AA / «рядом с рефом»); что спорно — с рекомендацией; дыры для других агентов; что не удалось и почему. Отчёт ≠ одобрение Влада.
