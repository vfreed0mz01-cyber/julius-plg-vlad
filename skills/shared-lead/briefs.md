# Шаблоны заданий агентам (лид)

Формат задания — `SKILL.md` §8а. Здесь — шапка и переменные по агентам.

## Шапка (всегда)
```
Ты — агент `<имя>`, запуск <X>. Проект projects/<name>/. Экран / тема: <№ и название>.
Следуй shared-runtime и своим скиллам.
Зона Figma: страница <имя> <id>, x <…>, y <…>.   (если пишет в Figma)
Файлы: <куда писать>.                              (свои, не общие)
Параллельно: <кто ещё и где>, не трогать.          (если есть)
```
Дальше — 3–8 строк только того, чего нет в скиллах и STATE: решения Влада этого раунда (цитатой), опора, особые входы, развилки, что точно не делать.

## Визуальный ресерчер
- **Е. Галерея под экран:** «Экран №N, содержание — лист `01-spec/screens/<N>.md`. Лучший прошлый вариант — <путь>, отвергнутое — <пути>. 8–12 живых экранов картинками, PNG-доска, рекомендуй топ-3.» Выход: `02-research/visual/gallery-<N>/`.
- **Е2. Оригиналы и замеры:** «Влад выбрал: <Г…> (главный — <Г…>: цитата), вторично <Г…>. Скачать оригиналы + 2–3 соседних экрана, замеры по списку `research-visual-anatomy`, `measures.md` + листы.»
- А–Д (стиль, рефы, цвет, ассеты, доска) — как в `agents/visual-researcher.md`.

## Бренд-дизайнер (только если бренда нет)
- «Бренда нет (STATE: <строка>). Рынок / язык: <…>. Конкуренты — `niche.md` <список>. Пожелания заказчика: <цитата>. Нельзя: <…>. Иду до остановки Б1 (направления картинкой).» Дальше — по одной остановке за запуск (Б2 знак ч/б, Б3 цвет + элемент + примерка, затем гайд).

## Дизайнер экрана
- **Всегда:** «Профиль: <mobile-card | desktop-table | desktop-dense> · Паспорт: <плоско | строго/премиум | со слоями>.» Остальное (карта до кадра, инвентарь, один вариант на грани) — в скиллах.
- **Направление по рефам:** «Направление <k> «<имя>» для №N, 3 итерации. Опора: <Г…> (что Влад в нём ценит — цитата) + <Г…> + <Г…>. Замеры: `gallery-<N>/measures.md`, оригиналы `originals/`. Фокус экрана: <одно главное действие>. Контент: <реальные названия / цифры или ссылка на STATE>.» Выход: кадр финала + прокрутка, доска рефов, аннотация; `03-design/screens/<N>-dir<k>.md|.png|-full.png|-iterations.png`.
- **Доводка выбранного:** «Влад выбрал <направление> (цитата). Правки: 1… 2… (каждая — одна строка, с источником: Влад / критик id). Развилка для Влада: <что> — одним фрагментом, не целым кадром. Чистка: <какие кадры в Archive>.»
- **Библия приложения** (после выбора направления и токенов, до второго экрана): «Напиши `03-design/bible.md` по выбранному <направлению, кадры id> и `tokens.json` v<k>.» Пишет тот же дизайнер, что делал направление.
- **Следующий экран в системе:** «Экран №M по библии `03-design/bible.md` и DS; содержание — лист №M; сверка с №1 «тот же продукт?».»
- **Case** (только по слову Влада): «Страница Case по `design-case`. Главная задача: было N шагов → стало M (`navigation.md`). Экраны: <node id>. Бренд: `brand.md` | заказчика. Для кого: Влад | клиент.»
- Концепт-стадия (несколько стилей) — только по прямой просьбе Влада; опора — выбранные им рефы, не названия стилей.

## Критик дизайна
- «Проверь <кадры: id финала / прокрутки> направлений <…>. Опоры: <Г…> (оригиналы …). Вайрфрейм <id>. Карта: `<экран>-composition.md`. Профиль: <…>, паспорт: <…>. Прошлые попытки: <пути>. Главное в этом раунде: <что проверить особо — напр. различимость, рядом с рефом, система статусов>.» Выход: `04-critic/<N>-design-<раунд>.md` (первой — таблица инвентаря, проход 1), `04-critic/inventory/*.json`, вердикт по каждому.

## Токенист
- «Выведи систему из выбранного Владом <направления / кадров id>, значения — из кадра и `measures.md`, с источником. Сравни с текущим `tokens.json` (что меняется). Preview картинкой.» Только после выбора направления.

## Сборщик DS
- «Перенеси `tokens.json` v<k> и компоненты выбранного направления (<список блоков экрана>) на страницу DS <id>; старые — в `/deprecated`, не удалять; компоненты в языке направления, не копии кита.»

## Карта FigJam
- «Обнови карту <процесса / проекта> <fileKey, секция id> под <что изменилось — ссылки на скиллы / листы как источник истины>. Дерево Влада не трогать.»

## Чек-лист перед отправкой
1. Зона Figma и свои файлы у каждого параллельного агента?
2. Решения Влада этого раунда — цитатой?
3. Нет повторения `shared-runtime` и скиллов?
4. Сказано, что **не** делать (из прошлых провалов этого экрана)?
5. Понятно, что считать готовым (выход и самопроверка)?
