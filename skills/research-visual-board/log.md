**Подпись под кропом — 3 строки по-русски** (Inter 12–13, ширина = ширина кропа): 1) что хорошо (с числом); 2) как у нас; 3) вердикт + почему в 3–5 слов. Над кропом — ID (14 Bold) и метки. **Метки вердикта:** зелёная «брать», жёлтая «идея», серая «настроение» — цвет + слово (не только цвет). Метка «концепт» — отдельная, нейтральная.
**Наш блок:** клон узла из утверждённого кадра (`node.clone()` в том же файле — картинка не нужна) внутри рамки с пунктиром 1 px (`dashPattern [6, 4]`), подпись «наш: №1 · 9:47». Клон, вставленный в auto-layout-рамку, наследует HUG / FILL и сминается или растягивается → сразу после `appendChild`: `layoutSizingHorizontal = layoutSizingVertical = "FIXED"` и `resize(w, h)` по размеру исходника; проверить `screenshot()`.

Строить инкрементально (`figma-use`: ≤ 10 операций на вызов), проверять `node.screenshot()` внутри `use_figma` — серверный `get_screenshot` переворачивает иврит. `clipsContent = false` у контейнеров с тенями. Доску строит **один** агент (два агента на одних узлах — нельзя).

### 4.3 Кропы: получить и подготовить
Все исходники — в `02-research/visual/crops/src/`, готовые кропы — `crops/<ID-лат>.png`.

1. **Mobbin:** `image_url` из результата поиска (полное разрешение, iOS @3x) — **скачать сразу**, ссылки живут 30 дней:
   `curl -sL -o crops/src/B4-2.webp "<image_url>"`
2. **Dribbble / Behance / Pinterest / сайты:** достать **оригинал картинки** со страницы (самый крупный `src` / `srcset` у `img`, `og:image`) через `read_page` / `javascript_tool` браузера и скачать `curl`. Типично: Dribbble — `cdn.dribbble.com/userupload/…`; Behance — `mir-s3-cdn-cf.behance.net/project_modules/…` (брать `max_1200` / `fs`); Pinterest — `i.pinimg.com/…`, размер в пути заменить на `originals`. Chrome Влада — только просмотр, никаких действий аккаунтом.
3. **Если оригинал не достать:** снимок видимой области экрана Pillow (`from PIL import ImageGrab; ImageGrab.grab(bbox=(x0, y0, x1, y1)).save(...)`, Windows) — окно браузера на экране, масштаб 100%. Последний вариант: качество ниже, замеры — «≈».
4. **Кроп** (Pillow; координаты в pt, `scale` 3 для Mobbin iOS):
```python
from PIL import Image
src, out, scale = "crops/src/B4-2.webp", "crops/B4-2.png", 3
x, y, w, h, pad = 20, 320, 356, 184, 12          # блок в pt (+ контекст 8–16)
im = Image.open(src); im.seek(0); im = im.convert("RGB")
box = [round(v * scale) for v in (x - pad, y - pad, x + w + pad, y + h + pad)]
box = [max(0, box[0]), max(0, box[1]), min(im.width, box[2]), min(im.height, box[3])]
im.crop(box).save(out, optimize=True)
```
Координаты блока — по картинке или `palette.py --scan-row / --scan-col` (`research-visual-anatomy`). Целые экраны — без кропа, только конвертация в PNG / JPG. Файл ≤ 10 МБ.

### 4.4 Вставка картинок в Figma
**`figma.createImage()` / `createImageAsync()` в `use_figma` не использовать** — в этом коннекторе они не поддерживаются (у скрипта нет сети, байты в скрипте не становятся ассетом). Рабочий путь по скиллу `figma-use` (references/api-reference.md → Images) — инструмент **`upload_assets`**:
1. `use_figma`: создать прямоугольники-места нужного размера (ширина строки, высота по пропорции кропа), имена `Crop/B4-2`; вернуть их id.
2. `upload_assets({ fileKey, currentPageId: <id страницы Research>, count: N, nodeIds: [id1, …], scaleMode: "FILL" })` → в ответе N одноразовых `submitUrl` в порядке `nodeIds`. Максимум 60 за вызов; **отправить все** до следующего вызова.
3. Отправить байты на каждый URL (параллельно можно):
   `curl -s -X POST -H "Content-Type: image/png" --data-binary "@crops/B4-2.png" "<submitUrl>"`
   Если сервер ответил ошибкой формата — вариант multipart из `figma-use`: `curl -s -X POST -F "file=@crops/B4-2.png;type=image/png" "<submitUrl>"` (имя файла становится именем слоя).
4. `use_figma`: проверить, что у `Crop/B4-2` `fills[0].type === "IMAGE"`, и снять `node.screenshot()`.
5. Тот же кроп в другой секции — не грузить заново: скопировать `imageHash` с уже заполненного узла (`fills = [{ type: "IMAGE", imageHash, scaleMode: "FILL" }]`).
6. SVG-иконки — `figma.createNodeFromSvg(svgString)` прямо в `use_figma` или `upload_assets` с `image/svg+xml` (станет вектором; `nodeIds` для SVG не действуют).

**Статус пути:** **Проверено 30.09.2026 (Mayors, запуск А): сработал вариант POST raw** — `curl -s -X POST -H "Content-Type: image/png" --data-binary "@crops/S1-2.png" "<submitUrl>"` → ответ `{"success":true,"imageHash":"…","placedOnNodeId":"<id>"}`; у прямоугольника `fills[0].type === "IMAGE"`, `node.screenshot()` показывает картинку. Multipart не понадобился. Подробности, проверенные на практике:
- `submitUrl` живёт **10 минут** и одноразовый → запрашивать `upload_assets` только когда кропы уже готовы, и POST-ить сразу (параллельно можно);
- `currentPageId` обязателен, иначе картинка уедет на первую страницу;
- Mobbin `image_url` (@3x) содержит **снизу полосу Mobbin 40 pt** (#2F2F2F, «curated by Mobbin») → перед доской и замерами отрезать низ `120 px` (при @3x; в замерах — флаг `palette.py --mobbin`); иначе `palette.py` считает её тёмной поверхностью;
- для доски хватает PNG шириной 600 px (кроп 200 pt × 3) — 0.1–0.7 МБ на экран; полное разрешение — в `crops/src/<ID>-screen.png` для замеров;
- **картинка больше 4096 px по стороне** (длинный скрин, доска иконок / фото) Figma ужимает до 4096 — мыло и сдвиг пропорций → резать Pillow на куски ≤ 4096 (каждый — свой прямоугольник, стык встык) или уменьшить до ширины доски до загрузки.
Если не сработал ни один вариант — не подменять картинки ссылками: кропы остаются в `crops/`, на доске — пустые места с ID, и об этом первой строкой в отчёте лиду (открытый вопрос).
