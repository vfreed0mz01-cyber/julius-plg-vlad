# Доска и остановки

Скачивание и подготовка кропов, вставка картинок в Figma (`upload_assets`) — `shared-research-howto` §4–5. Перед каждым `use_figma` — `figma-use`. История — `log.md`.

Имена файлов и слоёв — латиницей (кириллица ломает консоль Windows и путает С / C). Влад отвечает любым написанием.

## 2. Вход
- `style.md` (для ①); `refs.md`, `color-type.md`, `assets.md`, `plan.md` (для ②). Кропы `02-research/visual/crops/`.
- Файл вайрфреймов и страница `Research` — id из STATE «Figma-узлы». Нет страницы → **спросить Влада**, нет ли уже файла / страницы; создавать только после ответа.
- Утверждённые кадры (node id) — для строк «наш блок».

## 3. Структура доски
Страница `Research`, секции сверху вниз (Figma Section, имена английские), между секциями 400:

| Секция | Что внутри |
|---|---|
| `0 Header` | регистр и модификаторы; что решаем сейчас; **`Forks` — развилки остановки** (№ · варианты картинками · «рекомендую» · причина) — Влад видит их первыми; легенда вердиктов; «как отвечать»; дата и остановка |
| `1 Style` | 2–3 колонки-кандидата: стиль, 4–6 целых экранов (ширина 200), паспорт 9 осей коротко с числами, «почему подходит / риск», метка «рекомендую» у одного |
| `2 Pages` | строки по нашим экранам: наш кадр (пунктир) → реф-композиция и 1–2 экрана стиля (ширина 240); анти-рефы с меткой «не так» |
| `3 Blocks` | строка на блок: наш блок (пунктир) → 3–5 кропов (ширина 280); над строкой «Б4 <блок> — задача…» |
| `4 Details` | сетка кропов (ширина 200) |
| `5 Techniques` | приёмы (ширина 280); метки «фирменный?» и «через проектировщика» |
| `6 Color & Type` | образцы цвета (плашка + hex + контраст), сводка стиля; лестница шкалы на иврите шрифтами-кандидатами; заголовки; суммы и ₪ |
| `7 Assets` | «наши иконки × наборы» с подписью на иврите шрифтом проекта, таббар контур / заливка; слоты образов с кандидатами фото и заглушкой |

- **Подпись под кропом — 3 строки по-русски** (Inter 12–13, ширина = ширина кропа): что хорошо (с числом) · как у нас · вердикт + почему в 3–5 слов. Над кропом — ID (14 Bold) и метки.
- **Метки**: зелёная «брать», жёлтая «идея», серая «настроение» — цвет + слово; «концепт» — отдельная нейтральная. Проверка: у каждого кропа есть слово вердикта, не только цвет.
- **Наш блок**: клон узла из утверждённого кадра (`node.clone()`) в рамке с пунктиром 1 px (`dashPattern [6, 4]`), подпись «наш: №1 · 9:47». После `appendChild` в auto-layout: `layoutSizingHorizontal = layoutSizingVertical = "FIXED"` и `resize(w, h)` по исходнику, иначе клон сминается; проверить `screenshot()`.
- Кропы в строке — **одной ширины**. Строить инкрементально (≤ 10 операций на вызов), проверять `node.screenshot()` внутри `use_figma`. `clipsContent = false` у контейнеров с тенями. Доску строит один агент.
- Тексты доски — русский; образцы шрифта — иврит; слои — английский.

## 4. Остановки
**① Стиль** (после `research-visual-style`): секции 0 и 1. Сообщение:
```
Остановка ① — стиль. Доска: <ссылка на секцию 1 Style, node-id>
Коридор: <регистр · 50+ · RTL>. Кандидаты: С1 <стиль> · С2 <стиль> · С3 <стиль>.
Рекомендую С2 — <причина в одну строку>.
Ответь: «С2» (можно с поправкой: «С2, но фон холоднее»).
```
Только стиль — на доске нет блоков и иконок.

**② Всё остальное** (после refs + anatomy + assets): секции 2–7, шапка обновлена. В сообщении — только главные развилки, **≤ 4–5** (те же, что в `Forks`, у каждой картинка и рекомендация): реф для якорного блока, 1–2 фирменных приёма, набор иконок, шрифт. Остальное — строкой «остальные вердикты — по рекомендации, если не возразишь». Формат ответа: «Б4-2 ✓», «П3 нет — слишком игриво», «И1», «Ц: шрифт 2».

**После ответа**: решения → STATE (лид, словами Влада, с датой) и в `.md` ресерча («✓ Влад»). На доске — «✓» у выбранного; отклонённое серым, не удалять. Отказ с причиной → правило в соответствующий скилл (`shared-lead`).

## 5. Формат выхода
Страница `Research`: секции 0–7 · `crops/`, `crops/src/` · node id секций — в `plan.md` или отчёте лиду · сообщение Владу по §4.
