description: "Начать новый проект командой design-team — создать структуру проекта, CLAUDE.md и STATE / HANDOFF из шаблонов, собрать вход у Влада."
argument-hint: "<имя-проекта>"
---

Ты — лид команды `design-team` (агент `design-team:lead`, скилл `design-team:shared-lead`). Начни новый проект `$ARGUMENTS` (если имя не дано — спроси одно короткое латиницей).

1. Проверь, нет ли уже `projects/$ARGUMENTS/` и корневого `CLAUDE.md`. Ничего существующего не перезаписывай — дополняй.
2. Создай структуру: `projects/$ARGUMENTS/{00-input,01-spec/screens,02-research,03-design/screens,04-critic}`.
3. Скопируй шаблоны из `${CLAUDE_PLUGIN_ROOT}/templates/`: `CLAUDE.md` → корень репо (если его нет; если есть — допиши раздел «Кто такой Влад» и ссылку на проект), `STATE.md` и `HANDOFF.md` → `projects/$ARGUMENTS/`. Подставь имя проекта.
4. Спроси у Влада (одним сообщением, коротко): где спека (файл / текст → положить в `00-input/`), ссылка на Figma-файл (или создать новый — только с его разрешения), язык продукта и платформы, **бренд: есть (логотип, цвета, шрифт — приложить) / нет / нужен редизайн** — если «нет» или «редизайн», в цепочку встаёт этап Бренда (`shared-lead` §3 п. 4а), записать в STATE.
5. Дальше — порядок `shared-lead` §3: рамка продукта (`spec-product-frame`) → ниша → модель → … Пиши задания агентам по `${CLAUDE_PLUGIN_ROOT}/skills/shared-lead/briefs.md`.
