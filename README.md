# design-team 0.10.3

Плагин Claude Code «design-team» — команда дизайнера: спека → вайрфреймы → ресерч → дизайн → критик (Figma, иврит / RTL, mobile + web).

В 0.10.1: желания заказчика сверяются со спекой и ценой разработки (`skills/shared-lead` §4а). В 0.10.0: судья вкуса Влада (пары «да / нет» в `skills/shared-taste/verdicts.md`), проход по сценарию в роли (`critic-flow`), лёгкая проверка злых данных. В 0.9.0: реф стиля выбирает Влад, реф лейаута — 3–5 живых экранов той же задачи; режимы А (экран-донор) / Б (доноры по блокам) / В (стиль + лейаут); доводка по блокам; Pinterest в ресерче стиля; сгенерированные фото.

Установка: `/plugin marketplace add <путь или URL этой ветки>` → `/plugin install design-team@vlad-design`, или `claude --plugin-dir .`. Новый проект — `/design-start <имя>`.

> Публичная версия: картинки-примеры из клиентских проектов автора убраны из `skills/shared-taste/`, `skills/design-screen/examples/`, `skills/design-components/materials/`; ссылки на них в тексте остались.
